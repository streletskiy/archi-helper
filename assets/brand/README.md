# Archi Helper — пиксельный персонаж

Оба исходника имеют холст 32×32. `engineer.aseprite` содержит 76 кадров и восемь анимаций: `idle` (1–8), `reading` (9–20), `wave` (21–28), `inspect` (29–38), `measure` (39–48), `build` (49–58), `celebrate` (59–68), `idea` (69–76). Длительности кадров — 130–220 мс, в зависимости от действия. Слои Engineer, Helmet, Blueprint позволяют редактировать детали отдельно. `helmet.aseprite` использует ту же деталь каски без изменений.

Рисование, кадры, слои, теги и экспорт выполнены вызовами Aseprite MCP. Локальный журнал генерации: `mcp-build.json` (не публикуется, содержит пути машины). Сервер: https://github.com/MalloyTheDev/aseprite-mcp, коммит 8b7e95b6a69405f279c17227d5314dcb63ca5533. Aseprite 1.3.18.6.

GIF с именами тегов увеличены до 128×128 без сглаживания. Новые действия: приветствие рукой, изучение через лупу, измерение рулеткой, работа молотком, радостный прыжок и идея с лампочкой. Интерфейс использует PNG-полосу кадров `public/mascot-sheet.png` и метаданные `src/mascot-animations.json`; Aseprite не нужен пользователю приложения. На пустом экране чата персонаж периодически меняет занятие. Системная настройка уменьшения движения отключает анимацию.
