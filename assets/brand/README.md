# Archi Helper — пиксельный персонаж

Оба исходника имеют холст 32×32. `engineer.aseprite` содержит 20 кадров по 200 мс: тег `idle` (1–8) и `reading` (9–20). Слои Engineer, Helmet, Blueprint позволяют редактировать детали отдельно. `helmet.aseprite` использует ту же деталь каски без изменений.

Рисование, кадры, слои, теги и экспорт выполнены вызовами Aseprite MCP. Локальный журнал генерации: `mcp-build.json` (не публикуется, содержит пути машины). Сервер: https://github.com/MalloyTheDev/aseprite-mcp, коммит 8b7e95b6a69405f279c17227d5314dcb63ca5533. Aseprite 1.3.18.6.

`idle.gif` — отдых и пинок бумажного комка; `reading.gif` — чтение чертежа. GIF увеличены до 128×128 без сглаживания. Интерфейс использует PNG-полосу кадров `public/mascot-sheet.png`; Aseprite не нужен пользователю приложения.
