# Скрытое окно после автообновления

Проверено 21 октября 2026 года на Windows. Исправление: 0.2.5.

## Причина

Установщик завершил замену файлов на 0.2.4, а основной процесс приложения запустился с `--updated`. Интерфейс и подключение уже инициализировались, но главное окно с корректным заголовком имело `IsWindowVisible=false`. Это было отсутствие показа окна, а не отсутствие запуска процесса или повреждение установки. Уже работающий пользовательский экземпляр удалось показать без перезапуска и потери сессии.

Windows может применить значение `STARTUPINFO.wShowWindow=SW_HIDE` к первому показу окна, даже если Electron вызывает `show()`. На отдельном профиле установленной 0.2.4 запуск с `STARTF_USESHOWWINDOW` и `SW_HIDE` воспроизвёл невидимое окно. Обычный запуск того же приложения показывал окно.

Отдельно обнаружен оставшийся временный помощник более раннего обновления со статусом `applying`, без работающего установщика. Он не был процессом установленной 0.2.4; после проверки пути его завершили. Это отдельное устаревшее состояние, не основание считать установку 0.2.4 незавершённой.

## Изменение

Общий `showAppWindow` восстанавливает свёрнутое окно, вызывает `show()` и проверяет видимость. Если показ подавлен, цикл `hide()`/`show()` выполняет повторный показ после обработки унаследованного скрытого запуска. Затем окно получает фокус. Основное приложение и временный помощник отправляют подтверждение готовности только после успешного показа. Модуль включён и в отдельную временную копию помощника.

Обработчик повторного запуска также вызывает этот механизм: ярлык возвращает существующее скрытое окно, вместо одного лишь запроса фокуса.

## Граница проверки

Скрытый запуск проверяется на отдельном профиле с настоящим Windows `STARTUPINFO`, а видимость — через перечисление окон и `IsWindowVisible`. Для передачи управления отдельно проверяется временный экран обновления и переход к новой версии после статуса завершения установки. Имитация этого статуса проверяет показ и передачу управления, но не заменяет испытание установки с повышением прав.
