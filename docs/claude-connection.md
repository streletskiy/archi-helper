# Подключение Claude

В настройках провайдеров нажмите «Подключить Claude». Archi Helper ищет существующий официальный Claude Code в сохранённом расположении, стандартном пользовательском каталоге, PATH, WinGet и нативной установке npm. Найденная установка используется повторно. После подключения Claude появляется в общем списке провайдеров. Его дополнительные параметры, включая выбор другого расположения, открываются кнопкой редактирования этой плашки; до подключения настройки не показываются.

Если установки нет, приложение скачивает нативный Windows-бинарник с официального `downloads.claude.ai`, проверяет размер и SHA-256 по манифесту релиза, затем запускает его штатную команду `install` с проверенной версией. Выполняемый файл не изменяется, скачанные PowerShell/CMD-скрипты не запускаются. Установка использует пользовательский каталог и не требует прав администратора. Прогресс показывает поиск, загрузку, проверку, установку и вход; подключение можно отменить. Временный файл удаляется после завершения или ошибки. При повторной попытке сначала снова проверяется наличие установки.

Авторизацию проверяет `claude auth status`. Для нового подключения сначала используется обычный профиль Claude Code, включая настроенный `CLAUDE_CONFIG_DIR`. Если пользователь уже вошёл в подписку, повторный вход не запускается. Существующие отдельные профили Archi Helper также сохраняются. Выбранное расположение профиля привязывается к подключению, если CLI сообщает его в статусе. Вход в Claude Desktop сам по себе не гарантирует вход в отдельный CLI.

Если подходящего входа нет, приложение само запускает `claude auth login`. Официальный браузерный вход всё равно требует действия владельца аккаунта; приложение не вводит пароль, не подтверждает согласие за пользователя и не обходит MFA. Archi Helper не реализует собственный OAuth Claude, не читает файлы учётных данных и не копирует токены. Явная смена аккаунта через «Войти в подписку» или вход в Claude Console использует отдельный профиль приложения, чтобы сохранить текущий вход в терминале.

Отключение удаляет только связь с Archi Helper. Установка и вход Claude Code остаются доступны другим приложениям; `claude auth logout` автоматически не выполняется. При смене аккаунта или способа оплаты вне приложения запрос блокируется до повторного подключения.

Для подписки выберите вход в аккаунт Claude. По [документации Anthropic, проверенной 28 октября 2026 года](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan), `claude -p` с таким входом расходует лимиты подписки. Доступность зависит от аккаунта и правил Anthropic. Приложение не обещает безлимит и не переключается автоматически на API. Если Claude Code обнаружил API-ключ или облачные учётные данные, приложение предлагает войти в подписку или явно использовать текущий вход. Предусмотрены официальный вход в Claude Console и использование существующей авторизации CLI. Это отдельная оплата. Переменные окружения Claude Code не переписываются ради обхода его правил авторизации.

Список моделей использует документированные имена `default`, `sonnet`, `opus`, `haiku`. Это варианты выбора Claude Code, а не подтверждённый каталог доступных аккаунту моделей. Конкретные версии и доступность определяет Claude Code. Остатки лимитов можно проверить кнопкой «Управление лимитами».

## Выполнение задач

- Запуск без оболочки, через штатный `claude -p`, ввод и вывод `stream-json`. Использование бинарного файла подчиняется [условиям Anthropic](https://code.claude.com/docs/en/legal-and-compliance).
- Ответы и результаты инструментов сохраняются в обычной истории Archi Helper. При следующем обращении передаётся история без внутренних данных рассуждения другого провайдера. Отдельные возобновляемые сессии CLI не создаются. При переполнении контекста используется архив и сокращение истории приложения.
- Для каждого обращения создаётся временный MCP-сервер на `127.0.0.1` со случайным портом и ключом доступа. Он публикует только инструменты Archi Helper; сетевой адрес и ключ не сохраняются в конфигурации Claude Code.
- Встроенные инструменты файлов и командной строки Claude Code отключены. Другие MCP-конфигурации, проектные настройки, команды и hooks не подключаются. Все изменения проходят через существующие режимы работы и подтверждения Archi Helper, включая особые подтверждения рецептов.
- Вызовы инструментов выполняются последовательно. Намерение сохраняется до выполнения. Остановка и ошибка не повторяют операции автоматически. Уточнение во время выполняющейся операции применяется после её результата.
- Текст выводится постепенно; изображения передаются через MCP. Вложения остаются в рабочей папке чата и доступны файловым инструментам приложения.
- Загрузка установочного файла использует системный прокси Electron. Сам Claude Code, включая штатную команду установки, использует собственные сетевые настройки и окружение; системный прокси Electron автоматически на него не распространяется.

## Проверка

Штатные проверки: `npm test`, `npm run build`, `npm run package`. Проверки протокола используют только синтетические данные. Для проверки реальной подписки владелец должен завершить вход в браузере: после этого проверить короткий ответ, безопасное чтение файла, подтверждение изменения в режиме согласования, остановку, повторное открытие чата и отключение. Автоматические проверки не подтверждают доступность подписки и не выполняют изменения реального Archicad-проекта.
