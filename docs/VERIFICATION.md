- `npm ci`, `npm test` (44 теста) и `npm run package` прошли успешно: собраны TypeScript/интерфейс/Electron, установщик, portable EXE и карта блоков обновления. Синтаксис всех модулей Electron и сборочных скриптов проверен.

## Версия 0.2.5

- Установленная 0.2.4 воспроизводит невидимое окно при Windows-запуске с `STARTF_USESHOWWINDOW`/`SW_HIDE`. Собранная 0.2.5 при таком запуске показывает окно; видимость проверена через `EnumWindows`/`IsWindowVisible`, а не только наличие процесса.
- Временный экран обновления из готового Electron-приложения также виден после скрытого запуска. После контрольного статуса `complete` он запускает 0.2.5 и завершается после её подтверждения готовности; окно новой версии видно. Это проверка передачи управления, без повторной установки с повышением прав. [Разбор причины](reports/hidden-window-after-update.md).
- Повторный запуск через ярлык возвращает скрытый экземпляр без второго окна. Проверка выполнена на отдельном профиле.
- В интерфейсе проверены открытие и переключение двух длинных чатов в конце, появление кнопки после прокрутки вверх, переход вниз и сохранение места при новых потоковых сообщениях. Увеличение высоты содержимого после открытия сохраняет положение в конце. Кнопка также проверена в упакованной 0.2.5.
- Обе статьи базы приёмов загружаются через общий реестр; требование явного одобрения для надписи площади сохранено. Для интерактивных каталогов сверены поставляемые определения и официальная документация Graphisoft/Tapir; доступ к ячейкам и схемам реального каталога не заявляется.

## Версия 0.1.0

Проверено на Windows x64 с Archicad 27 build 5003 RUS и Tapir 1.7.2.

### Реальные сценарии

- Соединение с открытым Archicad, сведения о проекте и каталог из 316 инструментов.
- Создание тестовой полилинии после подтверждения, чтение координат и удаление созданного элемента. Рабочий PLN не сохранялся и не заменялся.
- Отказ от команды, запрет изменения в режиме просмотра, остановка задачи.
- Полный доступ: Python и перезапись файла без подтверждений; общий обработчик изменяющих MCP-команд проверен контрольной командой.
- MCP-ответ 16 МиБ принят без обрезки, сохранён полностью и прочитан фрагментом. Лимит транспорта — 128 МиБ.
- Проекты, сессии, восстановление истории, выбор моделей, экспорт диалога и прикрепление материалов.
- Изображения через URL/base64 в совместимом Chat Completions API, чтение через `view_image`, сохранение снимка в истории и повторный запрос к нему.
- Переносимая среда с минимальным системным PATH: Python, uv, создание и чтение PDF/PNG.
- Установка Windows-приложения и запуск portable EXE.
- Оформленные меню: мышь, клавиатура, Escape и сохранение выбранных значений.
- Единственное быстрое действие «Проверить на опечатки» подставляет аудит макетов с отчётом.
- Спрайты 32×32: 20 кадров, две анимации; каска во всех кадрах совпадает с логотипом. Уменьшение движения отключает анимацию.
- Окно шириной 1000 пикселей без горизонтального переполнения.
- Переключение RU/EN без перезапуска, сохранение языка, переводы настроек и быстрого действия. Подключение к Archicad и каталог 316 инструментов после переключения доступны.
- Реальные ответы модели: английский при русском интерфейсе и русский при английском, включая смену языка в одном диалоге.

### Автоматические проверки

GitHub Actions выполняет чистую установку зависимостей, TypeScript/Vite, проверку синтаксиса модулей и 9 тестов локализации и автообновления. Проверяются совпадение ключей и параметров RU/EN, сохранение языка, локализованные ошибки и английские инструкции агента. Кириллица в коде приложения, скриптах и workflow отсутствует. Релизный workflow дополнительно готовит переносимый Python, проверяет импорты, собирает Windows EXE и рассчитывает SHA-256.

Тесты автообновления проверяют ожидание завершения задачи, отмену отсчёта при вводе, откладывание до следующего запуска, отсутствие установки в Portable, сетевую ошибку и повторную проверку. Реальную установку следующей публичной версии можно проверить после появления такого релиза; эти тесты не заменяют проверку установщика между двумя версиями.

### Границы проверки

Наличие 316 инструментов не означает, что выполнена каждая команда. Другие версии Archicad и все возможные провайдеры отдельно не проверены. Совместимые провайдеры используют Chat Completions; подключение ChatGPT — Responses API. Проверка ChatGPT описана в [инструкции подключения](chatgpt-connection.md).

Пробный аудит получил реестр макетов и детали элементов; до итогового отчёта запуск был остановлен. Полная проверка текстов и визуального содержимого всех макетов этим запуском не подтверждена. Результаты модели требуют проверки архитектором.

Холодный запуск MCP может занимать десятки секунд; portable EXE дополнительно распаковывает среду. Python выполняется с правами текущего пользователя.
