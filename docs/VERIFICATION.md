# Проверка версии 0.1

Проверено на Windows x64 с Archicad 27 build 5003 RUS и Tapir 1.7.2.

## Реальные сценарии

- Соединение с открытым Archicad, сведения о проекте и каталог из 316 инструментов.
- Создание тестовой полилинии после подтверждения, чтение координат и удаление созданного элемента. Рабочий PLN не сохранялся и не заменялся.
- Отказ от команды, запрет изменения в режиме просмотра, остановка задачи.
- Полный доступ: Python и перезапись файла без подтверждений; общий обработчик изменяющих MCP-команд проверен контрольной командой.
- MCP-ответ 16 МиБ принят без обрезки, сохранён полностью и прочитан фрагментом. Лимит транспорта — 128 МиБ.
- Проекты, сессии, восстановление истории, выбор моделей, экспорт диалога и прикрепление материалов.
- Изображения через URL/base64 в совместимом Chat Completions API, чтение через `view_image`, сохранение снимка в истории и повторный запрос к нему.
- Переносимая среда с минимальным системным PATH: Python, uv, создание и чтение PDF/PNG.
- Установка Windows-приложения и запуск portable EXE.
- Оформленные меню: мышь, клавиатура, Escape и сохранение выбранных значений.
- Единственное быстрое действие «Проверить на опечатки» подставляет аудит макетов с отчётом.
- Спрайты 32×32: 20 кадров, две анимации; каска во всех кадрах совпадает с логотипом. Уменьшение движения отключает анимацию.
- Окно шириной 1000 пикселей без горизонтального переполнения.

## Автоматические проверки

GitHub Actions выполняет чистую установку зависимостей, TypeScript/Vite, проверку синтаксиса модулей и тесты поведения автообновления. Релизный workflow дополнительно готовит переносимый Python, проверяет импорты, собирает Windows EXE и рассчитывает SHA-256.

Тесты автообновления проверяют ожидание завершения задачи, отмену отсчёта при вводе, откладывание до следующего запуска, отсутствие установки в Portable, сетевую ошибку и повторную проверку. Реальную установку следующей публичной версии можно проверить после появления такого релиза; эти тесты не заменяют проверку установщика между двумя версиями.

## Границы проверки

Наличие 316 инструментов не означает, что выполнена каждая команда. Другие версии Archicad и все возможные провайдеры отдельно не проверены. Приложение использует Chat Completions.

Пробный аудит получил реестр макетов и детали элементов; до итогового отчёта запуск был остановлен. Полная проверка текстов и визуального содержимого всех макетов этим запуском не подтверждена. Результаты модели требуют проверки архитектором.

Холодный запуск MCP может занимать десятки секунд; portable EXE дополнительно распаковывает среду. Python выполняется с правами текущего пользователя.
