# Проверка приложения

## Автоматические проверки

Из корня репозитория:

```powershell
npm ci
npm test
npm run build
npm run package
```

Тесты проверяют подключения провайдеров, обработку ответов и вызовов инструментов, хранение истории, локализацию, телеметрию и автообновление. Для нативного провайдера проверяются поиск и установка CLI, проверка загруженного файла, повторное использование входа, отмена и ограничения локального MCP-подключения. Тестовые данные синтетические.

Сборка проверяет TypeScript и создаёт интерфейс, основной процесс и вспомогательные программы. Упаковка формирует установщик и portable EXE. Успешный результат подтверждается нулевым кодом завершения каждой команды.

GitHub Actions повторяет проверки для веток и pull request. Релизный workflow дополнительно готовит встроенную среду, проверяет её состав, собирает файлы выпуска и публикует контрольные суммы. Результаты конкретного коммита доступны в [Actions](https://github.com/streletskiy/archi-helper/actions).

## Проверка интерфейса

Используйте отдельный профиль через `--archi-data-dir` и только синтетические данные.

- Проверьте запуск, русский и английский языки, обе темы и минимальную ширину окна.
- Откройте настройки провайдеров: кнопки lumv, ChatGPT и Claude должны быть оформлены одинаково.
- До подключения Claude дополнительные настройки скрыты. После подключения он появляется обычной плашкой; параметры открываются кнопкой редактирования.
- Проверьте состояния загрузки, ошибки и отмены, сохранение подключения и повторный запуск.
- Проверьте открытие чатов, вложений, результатов инструментов и личных знаний.

## Проверка подключения и операций

Автоматические тесты с подставными ответами не подтверждают доступность реального аккаунта или результат работы в Archicad. Для такой проверки отдельно укажите версии приложения, CLI, Archicad и Tapir, используемый режим доступа и границы сценария.

Владелец аккаунта завершает официальный вход в браузере. Затем проверьте короткий ответ, чтение синтетического файла, подтверждение изменения в соответствующем режиме, остановку и продолжение чата. Для Claude дополнительно проверьте повторное подключение без нового входа и отключение от Archi Helper без выхода из CLI.

Операции Archicad проверяйте на специально созданном тестовом проекте с резервной копией. После изменения прочитайте результат обратно и убедитесь, что задача выполнена. Успешный ответ инструмента сам по себе этого не доказывает.

## Установщик и обновление

Проверьте запуск установленного приложения и portable EXE, доступность встроенных компонентов и сохранение профиля. Для изменений упаковки дополнительно проверьте обновление с предыдущего опубликованного выпуска и восстановление неполной встроенной среды.

В отчёты, изображения и публичные примеры включайте только синтетические данные. Не переносите сведения реальных проектов, переписки, пути, идентификаторы и исходные журналы.
