# Встроенные операции Archi Helper

Операции доступны всем подключённым моделям через общий исполнитель приложения. Модель задаёт область и параметры; приложение выполняет повторяющуюся последовательность, сохраняет полные результаты и проверяет явно перечисленные условия. Знания объясняют ограничения и выбор процедуры, а исполняемый код обеспечивает одинаковый порядок действий.

| Инструмент | Назначение и результат |
| --- | --- |
| `get_project_overview` | Соединение, сведения проекта, этажи, выделение, активное окно и наличие команд. Наличие команды в каталоге не гарантирует поддержку всех её параметров установленным расширением. |
| `inspect_elements` | Явные GUID, тип, выделение или вся модель; детали, свойства и количества пакетами. Полный JSON, компактная выборка, ошибки элементов, явный лимит. Это не чтение ячеек настроенного интерактивного каталога. |
| `capture_view` | Текущий или заданный вид, этаж/элементы для кадрирования, свежий PNG. Проверяются тип окна, целостность PNG и декодированная структура; изображение показывается пользователю и передаётся vision-модели одним вызовом. |
| `export_layout_package` | Сначала реестр LayoutBook и наборов Publisher без публикации, затем экспорт выбранных существующих PDF-наборов в новую папку. Проверка PDF, страниц, текстовое сопоставление с реестром и список неоднозначностей. |
| `audit_layout_text` | Русский/английский словарь, смешение алфавитов, повторы, глоссарий и заданные предпочтительные термины. OCR для изображений, предпросмотры страниц; JSON и Markdown из одного списка с координатами. |
| `apply_change_plan` | Предварительный план абсолютных присваиваний деталей/свойств, исходные значения, привязка к проекту, запись и обратное чтение. Повторное применение пропускает уже совпадающие значения. |

Для частичных настроек `SetDetailsOfElements` приложение учитывает пересечение вариантов схемы Tapir: например, `height` допустим и у стены, и у узловой точки. Только этот набор вариантов проверяется как объединение допустимых форм. Неизвестные поля, типы значений и сочетания полей вне одного варианта по-прежнему отклоняются; перед записью план читает соответствующие поля целевого элемента.

## Разрешения и локальные данные

Режим просмотра разрешает обзор, чтение, планирование экспорта, аудит локальных PDF и предварительный план изменений. Снимок может переключать окно и кадрирование, поэтому в этом режиме он недоступен. Экспорт и применение изменений также запрещены.

В режиме подтверждений снимки и фиксированный локальный экспорт выполняются в рамках запрошенной задачи. Применение плана показывает конкретные значения до/после и требует обычного подтверждения приложения. В полном доступе действует ранее выданное пользователем разрешение. Специальные правила знаний не отменяются: инструмент плана не поддерживает произвольный Python, GDL, создание/удаление элементов или относительные преобразования.

Операции не сохраняют PLN. Все промежуточные данные находятся в приватной папке чата: `.archi/operations/<id>/manifest.json`, результаты шагов и отчёты; планы и их состояние — в `.archi/change-plans`. Они не входят в сборку, знания или телеметрию.

Манифесты различают `completed`, `partial`, `unsupported`, `failed`, `cancelled` и `outcome_unknown`. Список `checks` сообщает выполненные проверки, а не доказательство правильности всей задачи. Частичное покрытие нельзя превращать в полный результат, скрывая лимит, ошибку страницы или недоступный раздел.

## Границы проверки

- Снимок подтверждает получение указанного типа окна и корректного изображения. Положение конкретных элементов и смысл результата требуют осмотра. Восстановление вида — попытка вернуть этаж или перспективу; точная исходная база/масштаб не гарантируются и это отражено в результате. Максимальный размер передаваемого изображения — 12 МиБ.
- Publisher сохраняет настроенный формат и состав. Инструмент не создаёт наборы и не меняет их настройки. Число страниц и совпадение номера/названия в тексте не доказывают происхождение страницы; отсутствующее совпадение не доказывает отсутствия листа. Обложки, повторяющиеся номера и листы без текста требуют отдельной проверки.
- Словарное отсутствие — кандидат, а не доказанная опечатка. Имена, сокращения и термины могут быть корректны. OCR может ошибаться; текст, изображения и визуальный осмотр имеют отдельное покрытие. Создание предпросмотра не считается визуальным осмотром.
- План принимает только значения, которые можно прочитать до и после записи. Свойства используют строковое представление Tapir; нормализация значения Archicad может вызвать несовпадение при проверке. Детали строго проверяются по текущей схеме. Изменение текста через API может заменить форматирование отдельных фрагментов — это необходимо учитывать при выборе операции.
- Перед записью проверяются все исходные значения и проект; перед каждым изменением значение проверяется ещё раз. Это не атомарная транзакция Archicad. При внешнем изменении, отмене, ошибке или разрыве связи часть записей могла завершиться. Автоматического отката и слепого повтора нет. Неизвестный результат разрешается чтением: если желаемое значение уже установлено, повтор пропускается; иначе необходим новый проверенный план.
- Для деталей сохраняется весь прочитанный снимок параметров и сравниваются также поля вне назначений. Дополнительное расхождение останавливает пакет со статусом `partial` и `requiresReview`; в отчёте остаются значения до/после. Это может быть зависимое изменение или особенность API — само сравнение не устанавливает причину. Возврат только заданных полей не считается восстановлением всего элемента.
- Стандартные лимиты: чтение до 1000 элементов пакетами по 100 (явно настраивается), план до 500 назначений, аудит до 5000 страниц и 5000 замечаний. Превышение покрытия отмечается явно. Большие полные ответы остаются в файлах.

## Поставка и проверка

`npm run runtime` подготавливает Python со Spylls, копирует неизменённые RU/EN Hunspell-словари с лицензиями и загружает закреплённые данные Tesseract OCR с проверкой SHA-256. Установщик и portable включают их как обычные файлы в `resources/runtime`, доступные Python вне ASAR. Для анализа документов сеть и дополнительная установка Python-библиотек не нужны. Происхождение компонентов описано в [THIRD_PARTY.md](THIRD_PARTY.md).

Автоматические проверки используют синтетические ответы и файлы: схемы, границы доступа, частичные результаты, неверное число ответов, повреждённый PNG, неоднозначное сопоставление, устаревший план, изменение проекта и неопределённый исход записи. Они не подменяют интеграционную проверку установленного Archicad.

Интеграционная проверка выполнена через чат приложения и существующее OAuth-подключение на отдельном синтетическом PLN: Archicad 27 build 5003, Tapir 1.7.3, поставляемые схемы Tapir 1.7.2. Проверены обзор, ограниченное чтение, снимки, инвентаризация/экспорт PDF, русский и английский текст, OCR отдельного растрового PDF, применение/повтор/восстановление целевых значений. Дополнительное расхождение поля деталей было обнаружено сравнением и остановило пакет для проверки. Полное исходное состояние подтверждено свежим чтением после повторного открытия сохранённого синтетического PLN без сохранения временных изменений. Словари и OCR также проверены в упакованном приложении в режиме просмотра. Это проверка перечисленных сценариев, а не всех типов элементов и версий Archicad.
