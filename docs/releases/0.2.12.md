# Archi Helper 0.2.12

- Добавлены короткие статьи справочника по проверенным возможностям Archicad, различиям версий и аудиту макетов. Индекс учитывает версию Archicad, build и Tapir; исторические наблюдения отделены от проверки текущего подключения.
- Экспорт существующего PDF-набора через Publisher в новую папку чата выполняется отдельным инструментом без дополнительного подтверждения. Проверяется появление PDF; полнота комплекта сверяется отдельно. Режим просмотра сохраняет запрет экспорта, исправления модели и сохранение PLN требуют обычных разрешений.
- Имена наборов публикации доступны через MCP без обходного Python-скрипта. Для Archicad 25 описаны правильный переход через databaseId, чтение дерева навигатора и обработка полных JSON-ответов.
- Аудит отдельно учитывает метаданные, текст и визуальный осмотр, проверяет вхождения по всему комплекту и согласованность итоговых Markdown/JSON.
- Кнопка Tapir скачивает официальный Windows-установщик, проверяет SHA-256 и сразу запускает его. Выбирать версию Archicad в настройках больше не нужно. Сохраняются прогресс, скорость загрузки и сообщения об ошибках; запуск установщика не выдаётся за завершённую установку.

В код и справочник включены только обобщённые технические выводы. Пользовательские отчёты, содержимое проектов, идентификаторы и пути не поставляются.

Для Windows скачайте **Archi-Helper-Setup-0.2.12-x64.exe**. Portable доступен отдельным файлом. Установленная версия обновится автоматически через стабильный канал.
