# Archi Helper 0.2.9

Компактный установщик и загрузка изменившихся блоков при автообновлении.

## Что изменилось

- **Одна копия Python.** Из упаковки исключена ссылка uv на ту же среду, которую архиватор раньше разворачивал во вторую полную копию. Вместе с ней удалён лишний кеш байткода.
- **Меньше служебных файлов.** Убраны файлы разработки MuPDF, справочник PyWin32, отладочные карты JavaScript и повторные копии библиотек интерфейса. Собранный интерфейс, Python, uv, MCP, обработка PDF и изображений сохранены.
- **Два языка Chromium.** Встроенный браузер содержит русский и английский языковые пакеты, соответствующие языкам приложения.
- **Сжатие LZMA.** Установщик и portable-сборка используют 7z/LZMA вместо ZIP с минимальным уровнем сжатия.
- **Дифференциальные обновления.** Вместе с установщиком публикуется карта блоков `.exe.blockmap`. Следующие обновления могут использовать неизменившиеся части сохранённого установщика и загружать только новые блоки. При отсутствии кеша или старой карты блоков выполняется полная загрузка.

## Установка и обновление

- **Archi-Helper-Setup-0.2.9-x64.exe** — установщик Windows x64; подключения, настройки и история сохраняются.
- **Archi-Helper-Portable-0.2.9-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Переход с 0.2.8 и более ранних выпусков требует полной загрузки: эти версии публиковались без карты блоков. Дифференциальная загрузка применяется между совместимыми выпусками с картами блоков и сохранённым установщиком; обновление Electron или Python может увеличивать размер загрузки.

Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
