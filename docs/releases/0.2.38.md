# Archi Helper 0.2.38

Выпуск дополняет справочник по работе с Картой видов и макетами и обновляет зависимости приложения.

- **Карта видов.** Описаны самостоятельные виды и клоны, обязательный идентификатор папки назначения и проверка каждой записи `navigatorItems` перед повтором.
- **Чертежи на макетах.** Для `CreateDrawings` описаны выбор источника и базы макета, коэффициент `scale`, номинальный масштаб `drawingScale` и повторное чтение созданного чертежа.
- **Зависимости.** Обновлены Electron до 44.11.5, Hono до 4.13.21, `@hono/node-server` до 2.1.11, dnspython до 2.9.2 и OpenTelemetry API до 1.45.2. Включены обновления JOSE, TanStack React Virtual и Vite.

Контракты команд проверены по поставляемым схемам и синтетическому JSON. Размещение и отображение объектов в PLN требуют отдельной проверки.

## Установка и обновление

- **Archi-Helper-Setup-0.2.38-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.38-x64.exe** — запуск без установки. Для обновления замените EXE.

Установленная версия обновится через стабильный канал. Python, uv, словари и данные OCR включены. `latest.yml` и `.exe.blockmap` используются для автообновления, а `SHA256SUMS.txt` содержит контрольные суммы файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов.
