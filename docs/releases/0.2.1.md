# Archi Helper 0.2.1

Исправлено слишком частое сжатие контекста в длинных задачах. Добавлены копирование сообщений и компактные уведомления.

## Что изменилось

- **Контекст по возможностям модели.** Убран общий порог в 180 тысяч символов. Размер рабочего контекста рассчитывается в токенах по данным провайдера и модели с запасом для ответа и рассуждения.
- **Автоматическая настройка подключений.** Недостающие параметры моделей дополняются из публичного каталога Models.dev без передачи ключей и истории чата. Существующие подключения обновляют параметры после запуска; затем сведения перепроверяются раз в сутки при запуске или переключении подключения.
- **Учёт реального расхода.** Приложение использует статистику токенов из обычных и потоковых ответов API. Для совместимых серверов без статистики сохраняется оценка расхода; если сервер сообщает о переполнении, история архивируется, сжимается, и задача продолжается. Обнаруженный лимит относится только к конкретному подключению и модели и не уменьшает контекст остальных.
- **Копирование сообщений.** Кнопка копирования доступна у сообщений пользователя, ответов помощника и ответа, который ещё поступает. Результат действия и ошибки показываются компактными уведомлениями.

## Установка и обновление

- **Archi-Helper-Setup-0.2.1-x64.exe** — установщик Windows x64. Установленная версия получит обновление автоматически; профиль приложения, подключения и история проектов сохраняются.
- **Archi-Helper-Portable-0.2.1-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Python и uv включены. `latest.yml` предназначен для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
