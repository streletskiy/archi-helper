# Archi Helper 0.2.23

- **Восстановление после неполного ответа.** Обрезанные и некорректные аргументы инструментов отклоняются до выполнения всего набора команд. Помощник сообщает о проблеме и один раз запрашивает исправленный ответ меньшими шагами, сохраняя ранее выполненную работу. Проверки действуют для совместимых API чата и Responses.
- **Лимиты выбранной модели.** Длина ответа берётся из каталога провайдера отдельно от размера контекста. Учитываются доступное место для запроса и модели с большими лимитами вывода, включая миллион токенов, когда такой предел заявлен провайдером. Единого потолка 16K нет; неизвестный лимит не подменяется размером контекста. Каталоги обновляются, ожидание длинных ответов увеличено.
- **Изображения видны пользователю.** Проверочные изображения, открытые помощником для просмотра, теперь показываются в чате по умолчанию. Для внутреннего анализа можно явно оставить изображение скрытым; просьба не присылать снимки учитывается. Снимки сохраняются отдельными копиями в истории и не требуют повторного показа другим инструментом.

Обработка больших JSON, восстановление и показ изображений проверены на синтетических данных. Отдельно проверена передача заявленного лимита в миллион токенов; генерация реального ответа такого объёма этим выпуском не заявляется. Возможность получить снимок зависит от поддерживаемого экспорта текущего вида Archicad. Новое интеграционное испытание изменений модели Archicad не выполнялось.

## Установка и обновление

- **Archi-Helper-Setup-0.2.23-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.23-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
