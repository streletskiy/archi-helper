# Archi Helper 0.2.10

Быстрее открываются большие переписки, меньше временных файлов при обновлении и компактнее код приложения.

## Что изменилось

- **Компактный основной процесс.** Код Electron и его зависимости собраны в один файл. Библиотеки больше не поставляются повторно отдельным деревом; их лицензии сохранены.
- **Лёгкий экран обновления Windows.** Вместо временной копии Electron примерно 317 МБ используется нативный EXE около 18 КБ с небольшой конфигурацией. Сохранены этапы установки и запуска, восстановление после ошибки, язык интерфейса и исходный профиль.
- **Быстрый список чатов.** Восстанавливаемый индекс хранит заголовки, даты и число сообщений. Для обычного обновления панели больше не требуется разбирать полные переписки. Исходные файлы сессий сохраняются; внешние изменения обнаруживаются автоматически.
- **Длинные переписки.** Интерфейс создаёт видимые сообщения и небольшой запас вокруг них. Прокрутка, копирование, ссылки, раскрытие инструментов и переход к последнему сообщению сохранены.
- **Потоковые ответы.** Несколько фрагментов объединяются перед отрисовкой кадра; переключение чата и завершение сообщения отменяют устаревшие фрагменты. Подробности группы инструментов загружаются при раскрытии.

На одном тестовом компьютере список 200 чатов ускорился с 105 до 2,4 мс, открытие переписки из 1000 сообщений — с 559 до 132 мс. Это результаты синтетического сценария, а не гарантия для любого компьютера. [Методика, ограничения и полные результаты](../reports/performance-0.2.10.md).

Версии и поставка uv, Electron и Python в этом выпуске не менялись.

## Установка и обновление

- **Archi-Helper-Setup-0.2.10-x64.exe** — установщик Windows x64; настройки и история сохраняются.
- **Archi-Helper-Portable-0.2.10-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Автообновление использует опубликованные `latest.yml` и `.exe.blockmap`; при наличии сохранённого установщика 0.2.9 могут скачиваться только изменённые блоки. При отсутствии кеша выполняется полная загрузка. Первое обновление из 0.2.9 ещё запускает прежний экран установки; новый компактный экран используется уже версией 0.2.10.

Python и uv включены. `SHA256SUMS.txt` предназначен для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
