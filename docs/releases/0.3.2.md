# Archi Helper 0.3.2

Откройте Archi Helper, затем запустите 3ds Max 2022 обычным ярлыком. Max сам загрузит скрипт из профиля Windows. Фоновая проверка подключения читает состояние и не открывает диалоги. Нативный модуль для этой версии Max не требуется.

Если сцена уже открыта при первой настройке, сохраните её и один раз перезапустите Max. Для продолжения в текущем окне чат подскажет полный путь к файлу для **Scripting → Run Script**.

При создании примитива можно задать размер в единицах сцены. Перед сохранением снимка Archi Helper обновляет активный видовой экран. Для разработчиков добавлен локальный JSON API для проверок чата и получения снимков через приложение.
