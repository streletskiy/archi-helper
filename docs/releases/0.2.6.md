# Archi Helper 0.2.6

Удобное управление проектами и сессиями: общая навигация слева, работа без проекта, архив и удаление.

## Что изменилось

- **Все проекты слева.** Под каждым проектом видны пять последних сессий. «Показать больше» раскрывает следующие; группы можно свернуть. Поиск охватывает названия проектов и сессий. Чаты без проекта собраны отдельно. Меню действий доступны прямо в списке.
- **Свободный старт.** Новую сессию можно начать без проекта. У поля сообщения есть выбор проекта с поиском, созданием нового и подключением существующей папки. Выбор проекта до первого сообщения сохраняет набранный текст и вложения. Кнопка «+» у проекта начинает сессию внутри него; Ctrl+N открывает общий стартовый экран.
- **Черновики.** Набранные сообщения и выбранные вложения сохраняются при переключении между чатами в текущем запуске. Пустой чат не создаётся при каждом нажатии «Новая сессия»; отмена выбора вложения также не оставляет пустую запись.
- **Архив.** Проекты и сессии можно архивировать и восстанавливать. Архивные чаты доступны для чтения, просмотра файлов и экспорта; отправка и запуск действий требуют восстановления. Архивирование проекта сохраняет состав его сессий, включая отдельно архивированные.
- **Удаление с подтверждением.** Сессию можно удалить вместе с перепиской, очередью и её рабочими файлами. Удаление проекта убирает его из приложения вместе с сессиями и файлами чатов. Исходная папка проекта и файлы в ней остаются на диске. В подтверждении показаны название и количество сессий проекта.
- **Названия проектов.** Проекты можно переименовать без переименования исходной папки.
- **Файлы в чате.** Ссылки, имена файлов в тексте и пути в строчном коде кликабельны: Проводник показывает соответствующий файл. Поддерживаются файлы чата, проектные пути, абсолютные Windows-пути и file-ссылки; блоки кода сохраняют обычный вид.
- **Прокрутка до конца.** Устранён остаточный зазор при открытии длинной сессии. Поздние изменения высоты учитываются, а чтение предыдущих сообщений не прерывается автоматическим возвратом вниз.
- **Экспорт и настройки.** Для экспорта переписки используется иконка Lucide Share. Из раздела «О приложении» убран блок «Данные и конфиденциальность».

## Установка и обновление

- **Archi-Helper-Setup-0.2.6-x64.exe** — установщик Windows x64; подключения, настройки и история сохраняются.
- **Archi-Helper-Portable-0.2.6-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Python и uv включены. `latest.yml` предназначен для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
