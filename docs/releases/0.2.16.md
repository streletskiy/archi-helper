# Archi Helper 0.2.16

- **Тёмная тема.** Приложение автоматически выбирает светлое или тёмное оформление по настройкам Windows и меняет его вместе с системой.
- **Выбор рядом с языком.** Кнопка в верхней панели открывает варианты «Как в системе», «Светлая» и «Тёмная». Ручной выбор сохраняется после перезапуска; вернуться к автоматическому оформлению можно в том же меню.
- **Все основные экраны.** Тема применяется к чату, полю запроса, боковой панели, настройкам, библиотеке знаний и подсказкам. Документы и изображения сохраняют свои исходные цвета.
- **Правило для знаний и примеров.** В правила разработки и инструкции помощника добавлен прямой запрет на публикацию сведений о реальных пользовательских проектах. Для общих справок и примеров допускаются обобщённые выводы и синтетические данные.

## Установка и обновление

- **Archi-Helper-Setup-0.2.16-x64.exe** — установщик Windows x64; настройки, история и личные знания сохраняются.
- **Archi-Helper-Portable-0.2.16-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
