# Archi Helper 0.2.2

Исправлена автоматическая проверка обновлений. Загрузка и установка теперь показываются на отдельном экране приложения.

## Что изменилось

- **Проверка при запуске.** Установленная версия сразу проверяет стабильные релизы GitHub и затем повторяет проверку каждый час. При ошибке сети или загрузки новая попытка выполняется автоматически через минуту.
- **Экран обновления.** Вместо рабочего интерфейса показывается одна карточка с этапами проверки, загрузки, установки и запуска. Во время скачивания видны процент, объём и скорость. Создание сессии горячей клавишей на этом экране заблокировано.
- **Установка внутри приложения.** Отдельное окно установщика не открывается. Экран приложения остаётся видимым во время подготовки и замены файлов и закрывается после готовности новой версии. Во время установки показываются этап и лоадер; процент относится к скачиванию.
- **Сохранение работы.** Перезапуск ждёт окончания текущей задачи и освобождения поля сообщения. Есть отсчёт и кнопка «Позже». При ошибке можно повторить обновление; после успешного перезапуска появляется уведомление с версией.
- **Ход выполнения задач.** Включены подготовленные в ветке разработки улучшения отображения прогресса и поиска инструментов Archicad.
- **Каталог API-команд.** В папке проекта сохраняется `.archi/api/catalog.json` с реальными MCP-инструментами, JSON-схемами Tapir и сигнатурами методов и типов Graphisoft SDK. Версия прямого API выбирается по подтверждённому подключению Archicad. Агент получает поиск по каталогу и указание читать точную схему вместо выдумывания команд и аргументов; Python получает путь к файлу через `ARCHI_API_CATALOG`.

## Установка и обновление

- **Archi-Helper-Setup-0.2.2-x64.exe** — установщик Windows x64. Профиль приложения, подключения и история проектов сохраняются.
- **Archi-Helper-Portable-0.2.2-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Новый экран установки работает после перехода на 0.2.2. Обновление из предыдущей версии выполняется её прежним механизмом; если автоматическая проверка не сработала, проверьте обновления в настройках или запустите установщик 0.2.2.

Python и uv включены. `latest.yml` предназначен для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
