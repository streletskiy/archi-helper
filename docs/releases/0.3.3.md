# Archi Helper 0.3.3

В 3ds Max 2022 можно попросить чат: «Поверни выделенный объект на 30° вокруг его локальной оси Z и проверь результат». Ассистент читает ориентацию объекта до и после поворота. Поворот доступен и вокруг мировых осей.

Для более сложных действий чат может выполнить Python внутри выбранного окна Max через встроенный `pymxs`. Запускайте Max с обычными правами пользователя. В режиме согласования Archi Helper показывает код перед выполнением. В режиме чтения выполнение Python заблокировано.

Если при обновлении Max 2022 уже открыт, сохраните сцену и перезапустите Max после запуска обновлённого Archi Helper. Новый адаптер загрузится автоматически.

Исправлена проверка поля `class` в `verify_finding`. Теперь ассистент может подтвердить тип объекта повторным чтением из Max.
