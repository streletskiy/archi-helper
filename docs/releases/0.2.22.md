# Archi Helper 0.2.22

- **Снимки по ходу работы.** Помощник может показывать созданные и изменённые места прямо в чате с короткими пояснениями. Снимки появляются до завершения задачи, видны при скрытых технических операциях и сохраняются в истории отдельными копиями. Показ доступен и с текстовыми моделями; возможность получить снимок зависит от поддерживаемого экспорта текущего вида Archicad.
- **Рекомендуемые модели.** GPT-6.1 Sol, Claude Haiku 5.5 и DeepSeek V4.1 Flash отмечены звёздочками и собраны в начале списка под заголовком «Рекомендуемые модели». Astra, Fable и Argon находятся внизу с пометкой «Дорогая модель». Группировка применяется к lumv и другим провайдерам по ID и названию модели, пересчитывается при обновлении каталога и сохраняет текущий выбор.
- **Заметное подключение.** Плашка подключённого Archicad в правом верхнем углу получила зелёный фон, обводку и точку-индикатор. Цвета согласованы для светлой, тёмной и системной тем; отсутствие подключения не отмечается зелёным.

Показ и сохранение изображений, группировка моделей и цвета интерфейса проверены на синтетических данных. Распознавание моделей дополнительно сверено с публичным каталогом lumv. Новое интеграционное испытание получения снимков или изменения модели Archicad этим выпуском не заявляется.

## Установка и обновление

- **Archi-Helper-Setup-0.2.22-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.22-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
