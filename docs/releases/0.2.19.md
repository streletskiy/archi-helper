# Archi Helper 0.2.19

- **Установка обновлений.** Неизменившийся Python сохраняется после проверки состава и SHA-256 всех файлов. Тысячи файлов больше не удаляются и не распаковываются заново. При изменении или повреждении среды установщик распаковывает полную копию сразу в конечный каталог; блоковая загрузка сохранена.
- **Возврат к работе.** Экран обновления закрывается сразу после появления готового окна приложения. Убрана дополнительная задержка в одну секунду.
- **Оформление.** Экран обновления всегда следует теме Windows и реагирует на её смену сразу. Поддерживаются светлая, тёмная и системная контрастная палитры.
- **Ход обновления.** Видны текущая операция и прошедшее время. При проверке Python отображаются процент этапа, число файлов и примерный остаток времени этого этапа. Для распаковки и замены файлов без точного счётчика остаётся индикатор работы; неизвестное время явно обозначено.
- **Надёжность.** Исправлено пропускание двух служебных файлов Python старым распаковщиком. Новая среда проверяется перед сообщением об успехе. Версии зависимостей, настройки, история и личные знания сохраняются.

В изолированных замерах медиана установки с неизменившейся средой снизилась с **167,6 до 24,1 с** (−85,6%, три запуска каждого варианта). Полное восстановление неполной среды заняло **79,3 с** в отдельном одиночном замере. Методика, результаты и ограничения описаны в [отчёте](https://github.com/streletskiy/archi-helper/blob/v0.2.19/docs/reports/update-install-0.2.19.md). Изменение упаковки однократно увеличивает долю загружаемых блоков при переходе с предыдущей версии.

Новое оформление и подробный ход обновления доступны для обновлений, запущенных из версии 0.2.19: при переходе со старой версии продолжает работать её прежний экран. Ускорение установки действует уже при обновлении до 0.2.19.

## Установка и обновление

- **Archi-Helper-Setup-0.2.19-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.19-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
