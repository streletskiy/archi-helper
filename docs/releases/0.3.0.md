# Archi Helper 0.3.0

- Добавлена поддержка Autodesk 3ds Max 2023–2027 для Windows. Archi Helper сам готовит модуль и находит открытые экземпляры. При первом подключении уже запущенного Max понадобится сохранить сцену и перезапустить Max.
- Из чата можно просмотреть сцену и материалы, проверить геометрию, получить снимок видового экрана, создать или изменить объекты. Изменения учитывают выбранный режим доступа. Каждый чат может работать со своим экземпляром Max одновременно с подключённым Archicad.
- Настройки телеметрии распространяются на 3ds Max. Версии приложения и модуля, публичные операции и проверенные шаги технических решений помогают учитывать совместимость. Названия сцен, пути, код и содержимое моделей остаются за пределами телеметрии.
