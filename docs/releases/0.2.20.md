# Archi Helper 0.2.20

- **Вложения.** Вставляйте изображения и скопированные файлы через Ctrl+V или перетаскивайте файлы в чат. Обычный текст вставляется как раньше. Вложения сохраняются в рабочей папке чата; исходные файлы не изменяются.
- **Краткий чат.** Служебные карточки инструментов скрыты по умолчанию. Их можно включить в разделе «Настройки → Приложение» переключателем «Показывать действия инструментов». Выбор сохраняется после перезапуска. Сообщения об ошибках и запросы разрешений остаются видимыми.
- **Надёжность ответов.** Исправлено смешивание JSON-аргументов разных вызовов инструментов, когда провайдер возвращает одинаковые или отсутствующие индексы. Разные вызовы разделяются по идентификаторам; неоднозначные фрагменты не выполняются.

В отдельном профиле проверены вставка текста, изображения и файла из буфера Windows, перетаскивание файла и переключение подробностей. Проверки используют синтетические данные; изменения модели Archicad для этой проверки не выполнялись.

## Установка и обновление

- **Archi-Helper-Setup-0.2.20-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.20-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
