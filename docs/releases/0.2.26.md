# Archi Helper 0.2.26

- **Безопасное чтение файлов.** Размер и содержимое файлов чата, изображений и статей базы знаний теперь читаются через один открытый файл. Подмена пути между проверкой размера и чтением больше не меняет выбранный файл; открытый файл закрывается и при ошибке.
- **Исправления обработки PDF.** Встроенный `pypdf` обновлён до 6.21.2. Версия устраняет три уязвимости, позволяющие специально подготовленным PDF вызывать чрезмерно длительную обработку.
- **Автоматические проверки безопасности.** В репозитории включены Dependabot alerts и расширенный анализ CodeQL для JavaScript/TypeScript, Python, C# и GitHub Actions. Зафиксированные Python-зависимости перенесены в стандартный `requirements.txt` в корне репозитория, чтобы GitHub учитывал состав встроенной среды.
- **Сайт приложения.** Добавлен сайт GitHub Pages со ссылками на актуальный установщик, portable-версию и документацию, светлой и тёмной темами и анимированным персонажем.

## Установка и обновление

- **Archi-Helper-Setup-0.2.26-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.26-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
