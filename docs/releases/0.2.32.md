# Archi Helper 0.2.32

Кандидат не опубликован: дополнительная интеграционная проверка выявила отклонение допустимого частичного изменения высоты при пересечении вариантов схемы Tapir. Возможности этого кандидата и исправление входят в 0.2.33.

- **Готовые операции для моделей.** Обзор проекта, пакетное чтение элементов, получение снимка, экспорт комплекта макетов, проверка текста PDF и планы изменений доступны через общий исполнитель приложения.
- **Обзор и чтение модели.** Контекст Archicad собирается одним вызовом помощника. Чтение элементов выполняется ограниченными пакетами, сохраняет полные результаты локально и явно сообщает об ошибках и неполном охвате.
- **Снимки и макеты.** Снимок Archicad проверяется и сразу показывается в чате. Экспорт существующих PDF-наборов публикации сопоставляет полученные страницы с реестром макетов и отмечает пропуски и неоднозначные совпадения.
- **Проверка текста без установки зависимостей.** Встроены словари русского и английского языков и данные OCR. Проверка PDF на подозрительные слова, смешение алфавитов и повторы создаёт согласованные JSON- и Markdown-отчёты. Документы обрабатываются локально; предложения требуют проверки человеком.
- **Проверяемые изменения.** Предпросмотр сохраняет значения до и после. Применение проверяет исходное состояние, записывает контрольные точки и повторно читает результат. Неизвестный исход не повторяется автоматически; отличия других возвращённых полей останавливают пакет для проверки. Автоматического отката нет.
- **Диагностика операций.** Статусы завершения, частичного результата и последующего чтения учитываются без передачи текста документов, значений элементов и путей к файлам.

Интеграция проверена на отдельном синтетическом PLN в Archicad 27 build 5003 с установленным Tapir 1.7.3 и поставляемыми определениями команд 1.7.2, через ChatGPT OAuth и GPT-6.1 Terra. Проверка отдельных полей не подтверждает всю геометрию. Сопоставление текста страниц не доказывает происхождение страниц; OCR не заменяет визуальную проверку. Экспорт использует уже настроенные наборы публикации и не создаёт их. Поддержка всех моделей и версий Archicad отдельным запуском не подтверждена.

## Установка и обновление

- **Archi-Helper-Setup-0.2.32-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.32-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python, uv, словари и данные OCR включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
