# Archi Helper 0.2.21

- **Понятный ход работы.** Вместо общего «Работаю…» отображаются текущая операция, обработка результатов или ожидание подтверждения. Автоматическое подключение знаний больше не добавляет служебные сообщения в чат.
- **Плавное появление ответов.** Новые ответы быстро появляются по мере поступления текста и плавно завершаются. История открывается сразу; системная настройка уменьшения движения отключает анимацию.
- **Ошибки инструментов.** При скрытых подробностях чата видна конкретная причина ошибки. Исправлена обработка лишней вложенности `elementId`, если точная схема команды ожидает объект с `guid`; идентификаторы и соседние поля сохраняются.
- **Знания на русском.** Названия, описания и тексты всех встроенных статей переведены на русский. Ограничения по версиям Archicad и границы ранее выполненных проверок сохранены.
- **Настройки.** Первым открывается раздел AI-провайдеров. «Знания и навыки» доступны из боковой панели; переход из окна настроек убран.
- **Быстрая проверка Python.** Проверка среды при обновлении использует системный SHA-256 Windows и до четырёх параллельных читателей. Проверки состава, размеров, содержимого и отсутствия ссылок сохраняются; повреждённая или неполная среда не используется повторно.

Проверки интерфейса и обработки аргументов выполнены на синтетических данных. Проверка среды отдельно проверена на повреждённых, отсутствующих и лишних файлах. Новое интеграционное испытание изменений модели Archicad этим выпуском не заявляется.

## Установка и обновление

- **Archi-Helper-Setup-0.2.21-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.21-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
