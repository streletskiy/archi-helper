# Archi Helper 0.2.27

- **Подключение Claude через официальный Claude Code.** Приложение находит существующий CLI и проверяет вход. Если CLI отсутствует, оно скачивает и проверяет официальный установочный файл, затем запускает установку. При необходимости открывается официальный вход в браузере; подтверждение аккаунта выполняет пользователь.
- **Общий блок подключения.** Кнопки lumv, ChatGPT и Claude оформлены одинаково. После подключения Claude появляется обычной плашкой в списке; дополнительные параметры открываются кнопкой редактирования.
- **Работа через инструменты приложения.** Нативный провайдер использует историю чата, вложения и действующие режимы доступа. Добавлены обработка потока ответа, отмены и ошибок подключения. Отключение от Archi Helper сохраняет установку и вход CLI.
- **Актуальная документация.** README сокращён до инструкций по запуску и настройке. Убраны заметки о старых версиях и сжатии установщика; обновлено руководство по проверке приложения.

## Установка и обновление

- **Archi-Helper-Setup-0.2.27-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.27-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
