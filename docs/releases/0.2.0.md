# Archi Helper 0.2.0

Обновление чата, настроек и работы с длительными задачами.

## Что нового

- **Провайдер и модель в чате.** Подключите несколько API-провайдеров и переключайтесь между ними в одной строке под сообщением. Для каждого подключения сохраняется выбранная модель.
- **Уровень рассуждения.** По умолчанию используется «Очень высокое / Xhigh» или ближайший поддерживаемый уровень. Список зависит от модели и возможностей API. Есть ручная настройка совместимости для API без этих сведений.
- **Автоматическое сжатие контекста.** Вместо остановки длинной задачи агент сохраняет сводку, исходный запрос и последние результаты и продолжает работу. Полная предыдущая история архивируется в папке проекта. При отказе API из-за переполнения контекст уменьшается и запрос повторяется. Убрана остановка после 40 шагов.
- **Свёрнутые группы инструментов.** Последовательные вызовы занимают одну строку со статусом и количеством операций. Группу и каждый результат можно раскрыть.
- **Переработанные настройки.** Навигация слева разделяет AI-провайдеров, Archicad и сведения о приложении. Версия, обновления, данные, встроенные компоненты и ссылки собраны в отдельные блоки. Соседние поля и кнопки имеют одинаковую высоту.
- **Компактный интерфейс.** Переключатель RU/EN доступен в верхней панели. Все элементы управления чатом помещаются в одну строку; стрелки выпадающих меню выровнены по центру.
- **Установка Windows.** Среда распаковывается сразу в папку приложения без повторного копирования тысяч файлов из временного каталога.

Совместимость рассуждения с инструментами определяется возможностями API провайдера. Для прямого DeepSeek API и OpenRouter учитывается их формат параметров; служебное состояние рассуждения сохраняется для продолжения вызовов инструментов.

## Установка и обновление

- **Archi-Helper-Setup-0.2.0-x64.exe** — обычная установка Windows x64. Обновление сохраняет профиль приложения, подключения и историю проектов.
- **Archi-Helper-Portable-0.2.0-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия проверяет стабильные GitHub Releases и устанавливает обновление после завершения работы и освобождения редактора. В 0.2 установщик загружается целиком. Python и uv уже включены.

Проверено с Archicad 27 и Tapir 1.7.2; нужен собственный API-ключ совместимого провайдера. Установщики пока не подписаны сертификатом издателя.

`latest.yml` используется автообновлением. `SHA256SUMS.txt` содержит контрольные суммы файлов. Архивы PyMuPDF и MuPDF — исходники встроенных сторонних компонентов; для запуска приложения скачивать их не нужно.
