# Archi Helper 0.2.30

- **Локальная память находок агента.** Полезные технические приёмы и особенности API сохраняются отдельно от личных знаний. При подборе учитывается точное сочетание версии Archicad, сборки и Tapir. Автоматически подключаются только находки с наблюдавшимся порядком успешных вызовов; предположения доступны вручную. Выполнение команд само по себе не подтверждает правильность вывода.
- **Управление находками в библиотеке.** Добавлены отдельные фильтры находок и архива, отключение, закрепление, восстановление и копирование в личные знания. После обновления проверенная встроенная статья может заменить явно указанную находку, сохранив её в архиве. Локальная память работает и при выключенной телеметрии.
- **Технические карточки для развития знаний.** При включённой передаче отправляются только карточки из разрешённых категорий, команд, полей схем, действий и проверок. Названия, ключевые слова и свободные пояснения остаются локально. Сетевые повторы сохраняют идентификатор события; отключение передачи отменяет отправку и очищает очередь. Включение находок в общий справочник требует проверки сопровождающим.
- **Стабильные блоки обновлений.** Архив встроенной среды включается в установщик без повторного сжатия NSIS. Это сохраняет возможность повторно использовать совпадающие блоки после небольших изменений среды. При первом переходе со старой упаковки архив потребуется загрузить заново; проверка целостности и восстановление среды сохраняются.

Проверки находок используют синтетические данные и подставные ответы инструментов. Новый интеграционный запуск в Archicad и проверка геометрии в PLN этим выпуском не заявляются.

## Установка и обновление

- **Archi-Helper-Setup-0.2.30-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.30-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
