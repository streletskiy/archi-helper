# Archi Helper 0.2.4

Обновление объединяет исправления установки, сообщения во время работы агента и отдельное хранилище файлов каждого чата.

## Что изменилось

- **Установка и автоматический запуск.** Экран обновления показывает подготовку, установку и ожидание готовности новой версии. Приложение запускается после замены файлов; запрос прав Windows и ошибки передачи управления установщику обрабатываются явно.
- **Сообщения во время работы.** Можно отправить уточнение для текущей задачи или добавить следующий запрос в очередь. Очередь сохраняется с чатом; сообщение можно удалить или применить сейчас. После остановки или перезапуска продолжение требует явного действия пользователя. Уже выполняемая команда Archicad не повторяется автоматически.
- **Файлы чатов в AppData.** История, вложения, скрипты, промежуточные JSON, изображения, результаты команд и журналы сохраняются в профиле приложения, отдельно для каждого проекта и чата. Кнопка «Файлы чата» открывает рабочую папку. Исходники проекта доступны отдельно; место экспорта переписки выбирает пользователь.
- **Существующие чаты.** Старые сессии и служебные файлы копируются в профиль с сохранением ссылок на результаты и изображения. Оригиналы остаются на месте. Произвольные файлы в корне проекта и `work/` автоматически не удаляются.
- **Понятные ошибки Python.** Исключение, лимит времени и остановка пользователем показываются отдельно от обычного вывода. Сохраняются длительность, stderr, полный журнал и конец большого вывода. Для ограниченной длительной работы агент может обоснованно увеличить лимит с 300 до 1800 секунд; после прерывания сначала проверяется фактический результат.
- **База приёмов для агента.** Добавлен справочник Markdown с выборочной загрузкой статей. Первый приём описывает замену отображаемой площади в конкретном штампе зоны без изменения контура и расчётной площади. Применение требует явного одобрения даже при полном доступе, проверки конкретного штампа и пробы на одной зоне.

## Установка и обновление

- **Archi-Helper-Setup-0.2.4-x64.exe** — установщик Windows x64. Подключения, настройки и история сохраняются.
- **Archi-Helper-Portable-0.2.4-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Исправленный механизм установки действует после перехода на 0.2.4. Если предыдущая версия при обновлении закрылась без автоматического запуска, откройте приложение через ярлык или запустите установщик 0.2.4.

Python и uv включены. `latest.yml` предназначен для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
