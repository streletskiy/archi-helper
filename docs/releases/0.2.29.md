# Archi Helper 0.2.29

- **Исправлено наблюдение вызовов Python.** Диагностика вложенных JSON API-вызовов теперь запускается и при строковом формате порта, который использует обычное подключение Archicad. Ранее корректный порт в таком формате приводил к пропуску наблюдателя. Проверка покрывает этот вариант подключения, частичные ошибки API, отмену задачи и отключение маршрутов; исходные значения и тексты ошибок по-прежнему не передаются.
- **Точное чтение деталей элементов.** Справочник поясняет допустимые поля верхнего уровня `GetDetailsOfElements.fields`, запрос вложенных свойств через `details` и обработку ответа, в котором присутствуют только выбранные поля.
- **Результаты создания элементов и атрибутов.** Добавлены правила разбора `elements` и `attributeIds`: каждая запись может содержать идентификатор либо ошибку. Описано отделение успешных результатов от ошибок и проверка состояния перед повтором. Новые примеры проверены на схемах и синтетическом JSON; проверка геометрии в PLN этим не заявляется.

## Установка и обновление

- **Archi-Helper-Setup-0.2.29-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.29-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
