# Archi Helper 0.2.11

Исправлена загрузка Tapir и добавлен прогресс установки в настройках.

## Что изменилось

- **Общий сетевой механизм.** Скачивание Tapir, подключения AI-провайдеров, OAuth и каталог моделей используют сетевой сеанс Electron. Приложение учитывает системный прокси Windows и подключается напрямую, когда прокси выключен.
- **Прогресс Tapir.** Настройки показывают проценты, скачанный объём и скорость, а также этапы проверки выпуска, контрольной суммы и установки. Повторная установка блокируется до завершения текущей операции.
- **Результат в настройках.** Сообщение об установке или инструкция для ручного добавления расширения остаются в карточке Tapir. Сохранены проверка SHA-256 и резервная копия заменяемого файла.
- **Ошибки соединения.** Вместо общего `fetch failed` отображается имя сервера и подсказка о проверке интернета и системных настроек прокси.

## Установка и обновление

- **Archi-Helper-Setup-0.2.11-x64.exe** — установщик Windows x64; настройки и история сохраняются.
- **Archi-Helper-Portable-0.2.11-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
