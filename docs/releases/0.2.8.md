# Archi Helper 0.2.8

Вход через ChatGPT, поддержка системного прокси и обновлённые настройки подключений.

## Что изменилось

- **Вход через ChatGPT.** Подключение аккаунта в браузере через OAuth с PKCE. Доступные модели и уровни рассуждения загружаются для текущего аккаунта; разрешения и доступность определяются OpenAI.
- **Работа с моделями.** Добавлен Responses API с потоковыми ответами, изображениями, рассуждением и локальными инструментами Archi Helper.
- **Системный прокси.** Авторизация, обновление и отзыв токенов, каталог моделей и запросы используют настройки прокси Windows.
- **Настройки подключений.** Кнопки lumv и ChatGPT с логотипами расположены в одну строку. Приветствие, выбор аккаунта и подтверждение отключения оформлены в стиле приложения.
- **Управление доступом.** Крестик у провайдера запрашивает подтверждение и отзывает доступ. Отмена сохраняет подключение, а при сетевой ошибке отзыв можно повторить. Регистрация сохраняется для повторного входа без дублирования.
- **Компактный чат.** В поле выбора отображается название провайдера без аккаунта. Управление лимитами перенесено в настройки; аватар из строки подключения убран.

Ручной ввод API-ключа и вход через lumv сохранены. В отдельном тестовом профиле проверены реальный вход, каталог моделей, вызов инструмента, перезапуск, обновление токенов, отзыв доступа и повторное подключение.

## Установка и обновление

- **Archi-Helper-Setup-0.2.8-x64.exe** — установщик Windows x64; подключения, настройки и история сохраняются.
- **Archi-Helper-Portable-0.2.8-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Python и uv включены. `latest.yml` предназначен для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
