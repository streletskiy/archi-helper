# Archi Helper 0.2.5

Исправлен скрытый запуск приложения после автообновления. Добавлены удобная прокрутка чатов и справочная инструкция по интерактивным каталогам Archicad.

## Что изменилось

- **Видимое окно после обновления.** Windows могла запустить установленное приложение со скрытым окном: процесс уже работал, но пользователь его не видел. Приложение и отдельный экран обновления теперь повторно показывают окно, если первый показ был подавлен скрытым запуском Windows. Подтверждение готовности отправляется после показа окна.
- **Повторный запуск через ярлык.** Возвращает существующее скрытое или свёрнутое окно.
- **Чат открывается в конце.** Переход между сессиями сразу показывает последние сообщения; поздняя загрузка изображений сохраняет положение в конце. Если пользователь прокрутил вверх, новый ответ не возвращает его вниз. Кнопка со стрелкой внизу диалога позволяет быстро перейти к последнему сообщению.
- **Интерактивные каталоги.** Агент получил статью о возможностях встроенного Graphisoft JSON/Python API и ограничениях Tapir. Он должен различать данные навигатора, свойства модели и ячейки/настройки ведомости, проверять команды текущей версии и предлагать подтверждённый экспорт или работу через интерфейс при отсутствии API. Прямое редактирование ячеек и схем каталога в приложение не добавлено.

## Установка и обновление

- **Archi-Helper-Setup-0.2.5-x64.exe** — установщик Windows x64; подключения, настройки и история сохраняются.
- **Archi-Helper-Portable-0.2.5-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Если предыдущая версия уже работает со скрытым окном и ярлык её не показывает, установите 0.2.5 скачанным установщиком. После перехода на 0.2.5 повторный запуск через ярлык также восстанавливает скрытое окно.

Python и uv включены. `latest.yml` предназначен для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
