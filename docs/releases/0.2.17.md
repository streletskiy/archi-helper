# Archi Helper 0.2.17

- **Ответы ChatGPT через OAuth.** Исправлена ошибка «модель вернула пустой ответ», возникавшая, когда полученный текст отсутствовал в итоговом событии потока. Приложение теперь сохраняет завершённый ответ и показывает его без повторного входа.
- **Продолжение работы.** Сохраняются порядок элементов, данные для продолжения рассуждения и завершённые вызовы инструментов. Текст не дублируется, если сервер повторяет его в итоговом событии.
- **Проверка завершения.** Оборванные, неполные и ошибочные потоки не принимаются за успешный ответ и не разрешают выполнение инструментов.

Разбор потока и продолжение вызовов инструментов проверены на синтетических данных. Пользовательские проекты, переписки и диагностические профили в выпуск не включены.

## Установка и обновление

- **Archi-Helper-Setup-0.2.17-x64.exe** — установщик Windows x64; настройки, история и личные знания сохраняются.
- **Archi-Helper-Portable-0.2.17-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
