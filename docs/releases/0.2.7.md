# Archi Helper 0.2.7

Подключение lumv через браузер, выбор способа подключения при первом запуске и безопасное управление доступом.

## Что изменилось

- **Вход через lumv.** Кнопка с названием и логотипом открывает авторизацию в системном браузере. После подтверждения доступа приложение подключает аккаунт и получает список доступных моделей. Копировать API-ключ вручную не требуется.
- **Выбор при первом запуске.** Если провайдеры ещё не добавлены, приложение предлагает войти через lumv или указать API-ключ. Ручное подключение совместимых провайдеров сохранено.
- **Безопасное подключение.** Используется OAuth с PKCE, одноразовым кодом и проверкой возврата из браузера. Токены хранятся в зашифрованном хранилище Windows; интерфейс их не получает.
- **Обновление доступа.** Приложение автоматически обновляет истёкший access-токен. Refresh-токены меняются при каждом обновлении; повторное использование старого токена отзывает соответствующее подключение.
- **Отключение аккаунта.** Доступ можно отозвать из приложения или кабинета lumv. Если сервер недоступен при отключении, соединение блокируется, а отзыв можно повторить после восстановления связи.
- **Другие провайдеры.** Добавлен общий реестр способов подключения: протокол авторизации отделён от названия, логотипа и адресов конкретного сервиса. Это основа для следующих интеграций; вход через ChatGPT/Codex в этом выпуске ещё не добавлен.

## Установка и обновление

- **Archi-Helper-Setup-0.2.7-x64.exe** — установщик Windows x64; подключения, настройки и история сохраняются.
- **Archi-Helper-Portable-0.2.7-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Python и uv включены. `latest.yml` предназначен для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
