# Archi Helper 0.2.37

Выпуск дополняет встроенный справочник процедурами проверки изменений в Archicad и обновляет зависимости приложения.

- **Поворот объектов.** Для `ModifyObjects` описаны целевой угол в радианах, чтение исходного и итогового значения и проверка каждой операции в пакете.
- **Обрезка крышей или оболочкой.** Новая статья объясняет форму запроса, как различать направления связи в `GetElementTrims` и как проверить результат снятия обрезки.
- **Создание окон.** В справочнике указано, как получить имя избранного или локализованное имя библиотечной части и разобрать ответ `CreateWindows` по записям.
- **Выделение.** Для `ChangeSelectionOfElements` описаны раздельные массивы результатов добавления и снятия выделения и повторное чтение при частичном исходе.
- **Зависимости.** Обновлены Electron до 44.10.2, electron-updater до 6.8.11, SDK MCP до 1.32.2, TanStack React Virtual до 3.14.26 и JOSE до 6.2.15.

Контракты команд проверены по поставляемым схемам и синтетическим JSON. Интеграционная проверка изменений геометрии в Archicad в этот выпуск не входила.

## Установка и обновление

- **Archi-Helper-Setup-0.2.37-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.37-x64.exe** — запуск без установки. Для обновления замените EXE.

Установленная версия обновится через стабильный канал. Python, uv, словари и данные OCR включены. Файлы `latest.yml` и `.exe.blockmap` используются для автообновления, а `SHA256SUMS.txt` содержит контрольные суммы файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов.
