# Archi Helper 0.2.15

- **Знания и навыки.** В боковой панели появился личный справочник. Создавайте записи с правилами оформления, особенностями проектов и порядком работы; редактируйте их и выбирайте, для каких проектов они действуют.
- **Нужные сведения подключаются автоматически.** Помощник подбирает подходящие записи по задаче и использует встроенные справки об инструментах, версиях Archicad и экспорте PDF. Для записи можно выбрать «По необходимости», «Только вручную» или «Всегда».
- **Быстрый выбор через `/`.** Введите `/` в поле сообщения, найдите запись по названию или тегу и добавьте её к запросу. Доступны стрелки, Enter/Tab и Esc. Выбрать запись можно и из боковой панели.
- **Личные записи сохраняются.** Они хранятся отдельно от программы, остаются при обновлениях и доступны в новых чатах. Предыдущие редакции сохраняются, удалённые записи можно восстановить из папки корзины.
- **Справочник в Markdown.** Встроенные инструкции и общие процедуры разделены на отдельные файлы; дополнения для версий Archicad находятся в своих папках. Пользовательские записи можно изменять через интерфейс или текстовый редактор.
- **Проще поле запроса.** Добавление файлов обозначено скрепкой. Кнопка знаний убрана из панели ввода. По умолчанию выбран «Полный доступ»; ранее сохранённый режим пользователя остаётся прежним. Подсказки объясняют пользу записей и когда их применять.

Автоматическое подключение справок, сохранение записей и интерфейс проверены на синтетических данных. Исторические сведения об Archicad сохраняют указание версии и границ проверки; новый интеграционный запуск с реальным проектом Archicad не заявляется. Пользовательские данные и тестовые профили в приложение не включены.

## Установка и обновление

- **Archi-Helper-Setup-0.2.15-x64.exe** — установщик Windows x64; настройки, история и личные знания сохраняются.
- **Archi-Helper-Portable-0.2.15-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
