# Archi Helper 0.2.28

- **Более точная диагностика Python и API.** Технические отчёты сохраняют разрешённые типы исключений и категории известных ошибок API. Отдельно распознаются ошибки операций внутри массивов созданных элементов и атрибутов.
- **Наблюдение вложенных вызовов Python.** При включённом развитии знаний запросы поставляемых Tapir-клиента и Graphisoft SDK через JSON API выбранного подключения получают отдельные диагностические записи. Видны частичные ошибки даже при успешном завершении Python, а также неизвестные исходы и ограничения покрытия. Скрипты, исходные значения, GUID и тексты ошибок не передаются; выключение маршрутов блокирует последующую отправку диагностики текущей задачи. Проверка ответа API сама по себе не подтверждает геометрию или достижение цели.
- **Уточнение встроенного справочника.** Описаны ограничение `ModifyRoofs` многоплоскостными крышами, проверка `roofClass` и отличие контракта изменения от `CreateRoofs`. Добавлен подбор статьи по запросам о крышах; уточнение основано на схемах и синтетическом JSON.
- **Удобнее писать сообщения.** Высота поля ввода чата автоматически подстраивается под объём текста.

## Установка и обновление

- **Archi-Helper-Setup-0.2.28-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.28-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
