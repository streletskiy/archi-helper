# Archi Helper 0.1

Первый выпуск помощника архитектора для Windows.

- Проекты и сессии с локальной историей.
- OpenAI-совместимые провайдеры и выбор модели.
- Подключение к Archicad через встроенный MCP и Tapir.
- Быстрое действие «Проверить на опечатки» для проверки макетов с отчётом.
- Изображения в диалоге, обработка PDF и встроенный Python.
- Режимы просмотра, подтверждения и полного доступа.
- Простой интерфейс и анимированный пиксельный инженер.
- Автоматическая загрузка обновлений из GitHub Releases и установка после завершения работы.

Для обычной установки выбирайте **Archi-Helper-Setup-0.1.0-x64.exe**. **Portable** работает без установки, но распаковывает среду при запуске. Python и uv уже включены. Portable обновляется вручную.

Проверено с Archicad 27 и Tapir 1.7.2. Нужны собственный API-ключ и совместимая модель. Установщики пока без цифровой подписи.

`SHA256SUMS.txt` содержит контрольные суммы файлов. Архивы PyMuPDF и MuPDF — исходники сторонних компонентов; для запуска приложения скачивать их не нужно. Файлы `latest.yml` и `.blockmap` используются автообновлением.
