# Archi Helper 0.2.36

Выпуск исправляет работу Gemini с инструментами и сохранённой историей диалога.

- **Вызовы инструментов Gemini.** Подписи модели сохраняются в потоковых и обычных ответах, остаются при загрузке истории и передаются вместе с соответствующим вызовом в следующем запросе. Исправлена ошибка `Function call is missing a thought_signature` после выполнения инструмента.
- **Продолжение старых чатов.** Добавлена совместимость с историей, в которой подписи отсутствуют. При смене провайдера или модели сохранённые подписи не переносятся в другой контекст.
- **Выбор модели Gemini.** Из списка исключены речевые, графические, транскрипционные и другие специализированные модели, не подходящие для инструментов помощника. При обновлении списка неподходящий сохранённый выбор заменяется доступной моделью. Отправка задачи с такой моделью сопровождается понятным сообщением.
- **Ошибки провайдера.** Ответы об ограничении частоты запросов и квоты Gemini показываются с пояснением дальнейших действий. Ошибки в ответах-массивах разбираются корректно.

Проверены автоматические сценарии сохранения подписей, восстановления истории, выбора моделей и обработки ошибок. Обмен с Gemini проверен на синтетических инструментах; новый интеграционный запуск Archicad при подготовке этого выпуска не выполнялся. Доступность конкретной модели зависит от ограничений и состояния сервиса Google.

## Установка и обновление

- **Archi-Helper-Setup-0.2.36-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.36-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python, uv, словари и данные OCR включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
