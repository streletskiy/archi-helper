# Archi Helper 0.2.35

Выпуск обновляет зависимости безопасности и дополняет встроенный справочник процедурами проверки изменений в Archicad.

- **Обработка PDF.** Встроенный `pypdf` обновлён с 6.21.2 до 6.21.4. Исправлены известные случаи зависания и чрезмерного потребления памяти при чтении и копировании специально подготовленных PDF.
- **Зависимости сборки.** Ветки `minimatch` 9 и 10 заменены на 11.0.4 с исправлением уязвимости обработки шаблонов. Старые ветки 3 и 5 сохранены для совместимости их потребителей: затронутого этой находкой кода в них нет. Обоснование и разбор предупреждений CodeQL о загрузке закреплённых OCR-данных приведены в [SECURITY.md](../../SECURITY.md).
- **Рельеф Mesh.** Справочник описывает структуру запроса создания, вложенность подлиний, допустимые параметры и проверку копии по прочитанным данным.
- **Восстановление API и расчёты.** Добавлены процедуры восстановления чтения после модального диалога и проверки пересечений с гранью с отдельной классификацией границы, промаха и вырожденного случая.
- **Проверка изменений.** Новые статьи разбирают индексы и блокировки слоёв, явные покрытия граней Morph и сравнение дополнительных полей стены после изменения высоты. Успешный ответ команды требует подтверждения свежим чтением; возврат одного параметра не доказывает полного восстановления состояния.

Статьи опираются на ранее выполненные проверки в отдельном синтетическом PLN: Archicad 27 build 5003, Tapir 1.7.3, поставляемые определения команд 1.7.2. Область подтверждения и ограничения приведены в каждой статье. Новый интеграционный запуск Archicad при подготовке этого выпуска не выполнялся; эти результаты не подтверждают поддержку всех версий, конфигураций и типов геометрии.

## Установка и обновление

- **Archi-Helper-Setup-0.2.35-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.35-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python, uv, словари и данные OCR включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
