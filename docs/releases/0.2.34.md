# Archi Helper 0.2.34

Выпуск исправляет подключение Claude и добавляет выбор модели и уровня рассуждения для Claude.

- **Подключение Claude.** После входа приложение больше не сообщает сразу, что аккаунт или способ оплаты Claude Code изменился. Стандартный профиль Claude Code передавался явным путём, и в этом режиме CLI не видел сведений об аккаунте. Подключения, сохранённые прежними версиями, исправляются автоматически. Если раньше подключение удалось только со второй попытки, потребуется одно повторное подключение.
- **Модели Claude.** Доступны «По умолчанию для аккаунта», Fable 5.1, Opus 5.5, Sonnet 5.5 и Haiku 5.5. Ранее выбранные Sonnet, Opus и Haiku автоматически переводятся на соответствующие модели.
- **Уровень рассуждения Claude.** Переключатель работает так же, как у других провайдеров: `low`, `medium`, `high`, `xhigh`, `max`. Выбранный уровень передаётся в Claude Code.
- **Рекомендуемые модели.** GPT-6.1 Terra отмечена как рекомендуемая.

Проверено с Claude Code 2.1.312 на подписке Claude: подключение через существующий вход, ответ в чате, сохранённый выбор модели после обновления каталога, а также короткие запросы CLI с каждой моделью и уровнями рассуждения. Передача выбранного уровня из окна чата подтверждена автоматическими проверками, отдельный живой запрос с переключённым уровнем не выполнялся. Вход в отдельный профиль через «Войти в подписку» в этом выпуске не проверялся. Доступность моделей зависит от аккаунта и правил Anthropic.

## Установка и обновление

- **Archi-Helper-Setup-0.2.34-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.34-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python, uv, словари и данные OCR включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
