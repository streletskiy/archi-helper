# Archi Helper 0.2.31

- **Находки сохраняются сразу.** Ошибки и последующее восстановление записываются в локальную память по ходу задачи. Контрольный пункт остаётся доступен, если задача позже прервалась или исчерпала контекст.
- **Проверка на устройстве пользователя.** Помощник может выполнить свежее разрешённое чтение и сравнить публичное поле ответа с ожидаемым значением. Для поддерживаемых присваиваний одному элементу приложение также сопоставляет изменённые поля с последующим чтением. Факт чтения, заявления модели и результаты сравнения учитываются отдельно.
- **Техническое решение для развития знаний.** Карточка содержит структурированные условия ошибки, изменение способа вызова, безопасные формы аргументов и ответов, а также связи с диагностикой, включая вложенные API-вызовы Python. Разбор подтверждённого технического контракта возможен удалённо без доступа к чату.
- **Передаются решения с доказательствами.** Непроверенные черновики остаются локально. При включённом развитии знаний отправляются наблюдавшиеся рецепты с фактической проверкой и явной областью подтверждения. Если последующая проверка опровергла ранее переданное решение, отправляется его отзыв. Новые доказательства передаются без ожидания недельного снимка.
- **Данные проекта остаются на устройстве.** Аргументы чтения, ожидаемые и полученные значения, идентификаторы элементов, код и содержимое чатов не входят в технические карточки. Настройки телеметрии и развития знаний продолжают управлять передачей во время работы.

Проверка отдельных полей или контракта API не подтверждает всю геометрию и цель задачи. Проверки выпуска используют синтетические данные и подставные ответы инструментов; новый интеграционный запуск в Archicad и проверка геометрии в PLN не заявляются.

## Установка и обновление

- **Archi-Helper-Setup-0.2.31-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.31-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
