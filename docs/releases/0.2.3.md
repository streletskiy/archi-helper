# Archi Helper 0.2.3

Исправлено мерцание изображений и скачки текста в сессии при наборе сообщения.

## Что изменилось

- **Стабильное отображение сессии.** При вводе текста уже загруженные изображения сохраняются на месте и не загружаются заново после каждого символа. Текст сообщений больше не смещается из-за повторного появления картинок.
- **Изображения в текущем ответе.** Завершённые сообщения и ответ, который ещё поступает, используют одинаковое отображение изображений и ссылок. Поступление нового текста и переключение языка интерфейса сохраняют уже загруженные картинки.

## Установка и обновление

- **Archi-Helper-Setup-0.2.3-x64.exe** — установщик Windows x64. Установленная версия получит обновление автоматически; профиль приложения, подключения и история проектов сохраняются.
- **Archi-Helper-Portable-0.2.3-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Python и uv включены. `latest.yml` предназначен для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
