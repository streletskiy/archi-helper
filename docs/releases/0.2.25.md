# Archi Helper 0.2.25

- **Причины ошибок и результаты инструментов.** При включённой передаче маршрутов приложение отправляет ограниченные технические отчёты для команд Archicad и Python: категорию результата, допустимые имена полей, типы входных и выходных данных, способ проверки и ссылку на предыдущую неудачную попытку того же инструмента или команды. Описание строится из фиксированных технических формулировок. Последующая успешная попытка сама по себе не доказывает исправления исходной проблемы.
- **Частичные ошибки команд Archicad.** Вложенные ошибки отдельных операций в `executionResults` распознаются даже при успешном ответе MCP. Помощник получает сведения о сбое, а статистика больше не считает такой вызов успешным. Эта обработка работает и при выключенной телеметрии.
- **Расширенная база знаний.** Добавлены процедуры поиска библиотечных частей и работы с GDL, выбора типов атрибутов, восстановления после частичного выполнения пакета, изменения перекрытий и Morph, сохранения отверстий и проверки геометрии. Подходящие статьи подключаются по задаче и используемым командам.

Исходные значения аргументов, полные тексты ошибок и вывода, переписка, Python-код, файлы и идентификаторы элементов остаются локально. Технические отчёты подчиняются существующим переключателям в разделе «Настройки → Приложение → Данные и конфиденциальность». Отключение передачи маршрутов прекращает и отправку отчётов; главный выключатель отключает всю телеметрию. Сохранённый выбор пользователя учитывается после обновления.

Сложный Python по-прежнему учитывается как один шаг: внутренний алгоритм не передаётся. Успешный ответ инструмента не подтверждает правильность модели или решение задачи. Штатные тесты, сборка, фильтрация диагностических данных и автоматический подбор знаний проверены; примеры в справочнике синтетические. Новое интеграционное испытание изменений модели Archicad этим выпуском не заявляется.

## Установка и обновление

- **Archi-Helper-Setup-0.2.25-x64.exe** — установщик Windows x64.
- **Archi-Helper-Portable-0.2.25-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
