# Archi Helper 0.2.18

- **Отступы в чате.** Сообщения и служебные карточки разделены устойчивыми отступами, которые учитываются при прокрутке длинной переписки.
- **Тёмная тема.** Логотип ChatGPT на кнопках входа и в диалогах стал светлым. Исправление работает при ручном выборе темы и при следовании настройкам Windows.
- **Приватность аккаунтов.** В списке подключённых провайдеров и редакторе подключения OAuth-аккаунты lumv и ChatGPT показаны только первыми двумя и последним символом; остальные символы, включая домен почты, скрыты звёздочками.
- **Обновления Tapir.** Настройки Archicad проверяют последний стабильный выпуск Tapir и сравнивают его с версией подключённого расширения. Проверку можно повторить вручную. Если есть обновление, кнопка запускает официальный установщик с проверкой SHA-256; после установки нужно перезапустить Archicad и подключиться заново. При неизвестной установленной версии приложение предлагает уточнить подключение.
- **Сообщения об ошибках.** Ошибки провайдера с текстовым описанием показаны без технической JSON-обёртки. Длинные подписи аккаунтов и кнопки обновления переносятся в пределах карточки.

Проверки интерфейса и сравнения версий используют синтетические данные. Установка расширения в рабочий Archicad не выполнялась.

## Установка и обновление

- **Archi-Helper-Setup-0.2.18-x64.exe** — установщик Windows x64; настройки, история и личные знания сохраняются.
- **Archi-Helper-Portable-0.2.18-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
