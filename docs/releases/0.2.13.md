# Archi Helper 0.2.13

## Что изменилось

- **Первое знакомство с приложением.** После подключения провайдера и выбора модели доступны четыре шага: знакомство, проверка связи, объяснение работы и первый запрос. Обучение можно сразу пропустить или повторить в настройках → О приложении. Для начала не требуется создавать папку проекта. Выбранный запрос появляется черновиком: пользователь сам редактирует и отправляет его.
- **Проверка подключения.** Встроенный JSON API Archicad проверяется отдельно от Tapir. Если Archicad отвечает, но расширение недоступно, интерфейс предлагает установку и повторную проверку. Для нескольких открытых экземпляров можно выбрать порт. Запуск установщика Tapir не выдаётся за подтверждённое подключение.
- **Облачка сообщений.** Сообщения пользователя располагаются справа, ответы помощника — слева. У пользователя нет аватара; у помощника — каска без фоновой плашки. Время и кнопка копирования находятся под соответствующей репликой, успешное копирование подтверждается рядом с текстом.
- **Анимации инженера.** Исходник Aseprite содержит восемь состояний и 76 кадров. Инженер приветствует, читает чертёж, изучает с лупой, измеряет рулеткой, работает молотком, придумывает и празднует. В обучении действия связаны со сценарием; на пустом экране чата персонаж меняет занятие. Учитывается системная настройка уменьшения движения.
- **Перезапуск после обновления.** Отсчёт сокращён до трёх секунд, добавлена кнопка «Перезапустить сейчас». Сохранены проверка незавершённых задач и возможность отложить обновление. Каска увеличена на экране обновления приложения и в отдельном нативном окне Windows. Обновление, пришедшее во время обучения, может продолжиться без зависания в ожидании.

Сценарии интерфейса и разделение состояний подключения проверены на синтетических данных и локальном имитаторе JSON API через Electron и встроенный MCP. Это не новый интеграционный запуск с реальным проектом Archicad. Демонстрационные записи, тестовые профили и пользовательские данные в релиз не включены.

## Установка и обновление

- **Archi-Helper-Setup-0.2.13-x64.exe** — установщик Windows x64; настройки и история сохраняются.
- **Archi-Helper-Portable-0.2.13-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
