# Archi Helper 0.2.14

- **Подсказки внутри интерфейса.** После настройки провайдера короткие карточки показывают поле запроса, подключение Archicad, выбор модели, режим доступа и выбор папки проекта. Подсветка и указатель связывают карточку с нужным элементом.
- **Можно сразу работать.** Поле запроса и остальные элементы остаются доступными. Esc, «Пропустить» или клик в рабочую область завершают показ; подсказки можно повторить в разделе «О приложении».
- **Подключение по ситуации.** Текст учитывает состояние Archicad и наличие Tapir; из карточки можно открыть настройки подключения. Показ подсказок сам по себе не запускает Archicad, установщик или отправку запроса.
- **Папка необязательна.** Обучение объясняет работу без проекта и добавление файлов к сообщению. Для начала работы создавать папку не требуется.
- **Адаптация к окну и настройкам.** Карточки размещаются рядом с элементами и учитывают размеры окна. Поддерживаются русский и английский языки, клавиатура и системная настройка уменьшения движения. Обновление приложения может продолжиться во время показа подсказок.

Интерфейс проверен на синтетических данных, включая состояния подключения Archicad и Tapir. Это не новый интеграционный запуск с реальным проектом Archicad. Демонстрационные записи и пользовательские данные в релиз не включены.

## Установка и обновление

- **Archi-Helper-Setup-0.2.14-x64.exe** — установщик Windows x64; настройки и история сохраняются.
- **Archi-Helper-Portable-0.2.14-x64.exe** — запуск без установки; обновляется вручную заменой EXE.

Установленная версия обновится через стабильный канал. Python и uv включены. `latest.yml` и `.exe.blockmap` предназначены для автообновления, `SHA256SUMS.txt` — для проверки файлов. Архивы PyMuPDF и MuPDF содержат исходники встроенных сторонних компонентов; для запуска они не нужны.
