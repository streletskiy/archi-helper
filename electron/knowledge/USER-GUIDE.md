# Личные знания Archi Helper

Эта папка находится в профиле приложения, отдельно от установки и чатов. Обновления её не заменяют. Резервируйте всю папку вместе с профилем. Файлы — обычный UTF-8 Markdown; их можно редактировать в интерфейсе или внешнем редакторе. После внешнего редактирования нажмите «Обновить».

- `global/` — записи для всех проектов.
- `projects/<projectId>/` — записи конкретного проекта, включая отдельное пространство чатов без проекта. Удаление проекта не удаляет эти записи. Скопируйте нужный файл в `global/`, если он должен стать доступен другим проектам.
- `.history/` — предыдущие версии при сохранении через интерфейс.
- `.trash/` — удалённые через интерфейс записи. Для восстановления скопируйте файл в `global/` или нужную папку проекта. Автоматической очистки нет.

Минимальная запись:

```md
---
title: "Правила оформления отчёта"
summary: "Порядок разделов и единицы измерения в отчётах проекта."
kind: "skill"
activation: "manual"
enabled: true
tags: ["отчёт", "report"]
archicad: []
---

Сначала перечисли проверенные факты, затем вопросы для уточнения.
```

Заголовок поддерживает одну строку на поле: обычную строку или JSON-строку в двойных кавычках, JSON-массив, true/false. Сложный YAML не поддерживается. Обязательны title, summary и непустой текст. `kind`: knowledge (справка) или skill (порядок действий). `activation`: auto (доступно через поиск), manual (только выбор в запросе), always (в каждом запросе подходящего проекта и версии). `archicad: []` — любые версии; `[25, 27]` — только указанные. При неизвестной версии записи с ограничением автоматически не подключаются.

Для подключения записи откройте «Знания и навыки» в боковой панели или введите `/` в поле запроса. После `/` можно набрать название или тег. В списке работают мышь, стрелки, Enter/Tab для выбора и Esc для закрытия; выбранная запись появляется над полем запроса. Само `/название` убирается из текста после выбора. Файлы добавляются кнопкой со скрепкой. Новый профиль использует «Полный доступ»; сохранённый ранее режим не изменяется.

В режиме «По необходимости» подходящие записи подключаются автоматически по тексту задачи; для личных записей важны информативное название и теги. Для встроенных процедур заданы дополнительные ключевые слова и связи: например, PDF-экспорт автоматически подключает инструкцию аудита, маршруты API и сведения о текущей версии. В чате показаны названия подключённых статей. Автоподбор ограничен 6 статьями и 12 000 символов с учётом зависимостей; остальное агент может прочитать через поиск.

Поиск локальный: слова из названия, описания, тегов и текста; это не семантический поиск. Добавляйте русские и английские теги. Дополнительный агентский поиск возвращает короткую страницу результатов, затем нужный текст по ID. Ручные записи не доступны модели до выбора пользователем. Отключённые записи не подключаются. Содержимое уже отправленных записей остаётся в истории чата; для исключения ранее отправленной информации начните новый чат.

Лимиты: файл 64 КиБ, текст 24 000 символов; «Всегда» — 2 000 на запись и 6 000 суммарно; ручное подключение — до 8 записей и 24 000 символов суммарно. Превышение даёт ошибку, текст не обрезается молча. Записи отправляются выбранному AI-провайдеру только при подключении или чтении агентом. Не храните здесь пароли и ключи.

Навык — инструкция для модели, а не исполняемый плагин. Он не меняет режим доступа, не разрешает действия и не заменяет текущий запрос. Системные статьи редактируются только разработчиками и не смешиваются с личными.
