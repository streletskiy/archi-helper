# Интерактивные каталоги и API Archicad

Область проверки определений: встроенный Graphisoft JSON/Python API, каталог поставляемого SDK для Archicad 27 build 3001 и определения Tapir 1.7.2. На другой версии сначала проверяйте доступные команды. Эта статья не добавляет отсутствующие функции в подключение.

## Что нужно различать

Интерактивный каталог (Interactive Schedule, интерактивная спецификация, ведомость) — представление данных модели в навигаторе. Его строки и ячейки, критерии отбора, поля, объединения, итоги и оформление отличаются от элемента навигатора и свойств исходных элементов.

Tapir расширяет встроенный JSON API Archicad. Отсутствие команды Tapir не означает, что операция недоступна встроенному API. Однако переход на пакет Python `archicad` не открывает все возможности Archicad: это оболочка документированного JSON API, а не доступ к любому внутреннему модулю или C++ DevKit.

В проверенном каталоге нет документированных команд чтения/записи ячеек интерактивного каталога или редактирования его схемы и оформления. Наличие `ScheduleItem` в типах навигатора или типа окна интерактивного каталога не доказывает доступ к его содержимому.

## Выбор пути

| Задача | Поддерживаемый путь и граница |
| --- | --- |
| Найти представление, его GUID или тип | Проверьте `GetNavigatorItemTree` и `GetNavigatorItemsType` встроенного API; используйте фактический ответ текущего проекта. Это метаданные навигатора, не строки ведомости. |
| Прочитать исходные значения модели | Проверьте `GetElementsByType`, методы поиска свойств, `GetPropertyValuesOfElements` и нужные типы. Соберите отдельную таблицу с явными критериями, единицами и правилами группировки. Это самостоятельная выборка, не точная копия существующего каталога. |
| Изменить значение свойства, которое выводится в каталоге | Проверьте доступность и редактируемость свойства, точную схему `SetPropertyValuesOfElements`, целевые GUID и права. Это изменение модели, влияющее также на другие виды. Пустое, недоступное и вычисляемое свойства обрабатывайте отдельно. |
| Получить точный существующий каталог, итоги или оформление | Используйте экспорт из окна каталога Archicad в подходящий формат: табличный текст/XLS для значений, PDF для вида. Если подходящего инструмента экспорта нет, попросите пользователя выполнить экспорт; не утверждайте, что он сделан. Обрабатывайте полученный файл в рабочей папке чата. |
| Изменить схему, критерии, поля, объединения или оформление | Сначала ищите документированную команду для установленной версии. Если её нет, объясните ограничение и предложите правку в интерфейсе Archicad. Отдельная разработка Add-On возможна только после проверки соответствующей функции DevKit и её доступности; готового универсального обхода здесь нет. |

## Порядок действий агента

1. Уточните по задаче, нужны ли метаданные навигатора, исходные свойства модели, точные строки существующей ведомости или её схема. Не подменяйте требуемый результат собственной таблицей без объяснения.
2. Выполните `TestConnection`. Через `get_api_catalog` отдельно проверьте источники `mcp`, `tapir` и `graphisoft`, затем запросите точное найденное имя и полную схему/сигнатуру. Используйте SDK, соответствующий подтверждённой версии и сборке.
3. Предпочитайте доступную MCP-команду. Если нужная операция документирована только во встроенном Graphisoft API, допустим прямой вызов через `run_python` и пакет `archicad`. Подключайтесь к явно выбранному порту текущей сессии, используя `ARCHICAD_PORT`, а не к первому случайному открытому экземпляру. Точные конструкторы типов берите из каталога; не выдумывайте имена команд и полей ответа.
4. Не перебирайте предполагаемые названия вроде `GetScheduleData` или `SetScheduleSettings`. `ExecuteAddOnCommand` исполняет только реально зарегистрированные команды с известными namespace, именем и параметрами. Он не вызывает произвольную функцию C++ и не предоставляет доступ к внутренностям модуля каталогов.
5. Сохраните полный ответ/экспорт в рабочей папке чата. Сначала изучите ключи, ошибки и небольшой образец. Для собственной выборки явно укажите критерии и охват, проверьте количество элементов, единицы, округление, группировку и итоги; не выдавайте её за содержимое настроенной ведомости.
6. Изменяющие вызовы проходят обычный режим разрешений приложения. Перед изменением свойств объясните, что меняется модель; сохраните исходные значения, проверьте пробу и ошибки по элементам. Не исправляйте несоответствие ведомости скрытой заменой текста, площади или геометрии. Сохранение/публикация проекта требуют отдельного запроса пользователя.

Если вызов не выполнен или завершился ошибкой, не сообщайте об успешном доступе к каталогу. После двух неудач одного подхода переходите к подтверждённой альтернативе. Возможность чтения/изменения каталога через отдельный C++ Add-On должна проверяться самостоятельно; наличие DevKit не является подтверждением такой возможности.

## Проверка и источники

Проверены определения поставляемых команд и сигнатур; чтение/редактирование ячеек реального проекта этим способом не проверялось и не заявляется. При обновлении API пересматривайте ограничения статьи.

- [Graphisoft: Python API Archicad 27](https://archicadapi.graphisoft.com/archicadPythonPackage/archicad.releases.ac27.html) — встроенные команды навигатора, свойств и зарегистрированных Add-On-команд.
- [Tapir: назначение и документация команд](https://github.com/ENZYME-APD/tapir-archicad-automation) — расширение встроенного JSON API; доступность зависит от версии установленного Add-On.
- [Graphisoft: Interactive Schedule](https://help.graphisoft.com/AC/29/INT/_AC29_Help/055_InteractiveSchedule/055_InteractiveSchedule-1.htm) — связь с моделью, размещение в навигаторе и форматы экспорта.
- [Graphisoft: API Reference](https://archicadapi.graphisoft.com/api-reference) — отдельный C++ DevKit и требования совместимости Add-On.
- В репозитории: `electron/api_catalog.py` извлекает сигнатуры поставляемого Python SDK, `electron/api-catalog.mjs` выбирает выпуск по соединению, `vendor/archicad-mcp/src/archicad_mcp/tapir/command_definitions.js` содержит определения Tapir. Сгенерированный каталог доступен агенту через `get_api_catalog`.
