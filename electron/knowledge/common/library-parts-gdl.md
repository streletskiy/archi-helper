# Библиотечные элементы и GDL

Основание — поставляемые схемы Tapir в `command_definitions.js` и `common_schema_definitions.js`, а не пользовательский проект. Правила структуры проверяются на синтетических JSON. Новый интеграционный прогон в отдельном PLN не заявляется; перед изменениями сверяйте доступность и точную схему текущего подключения. Имена и типы GDL зависят от библиотечной части.

## Найти часть и прочитать параметры

1. Через `find_tools` получите полную схему нужной команды по точному имени. В `GetAvailableLibraryParts` входной фильтр называется `filterByTypeId`; `typeId` — поле описания найденной части, а не имя аргумента. Синтетический пример запроса: `{"filterByTypeId":"Window"}`.
2. Ответ содержит `libraryParts` и `skippedCount`. Пустой массив вместе с пропущенными записями не доказывает отсутствия библиотеки. Учитывайте частичное покрытие и не придумывайте GUID библиотечных частей.
3. Для существующего элемента вызовите `GetGDLParametersOfElements` с `elements`. Сначала снимите оболочку MCP: используйте `structuredContent`, иначе декодируйте JSON из текстового содержимого. Внутри ответа команды массив называется `gdlParametersOfElements`, а список параметров элемента — `parameters`. Ошибка `KeyError` может означать, что прочитана оболочка, а не отсутствие поля у команды.
4. Прочитайте `name`, `type`, `value`, `isLocked`, допустимые значения и ограничения конкретного параметра. Не заменяйте техническое имя локализованным `displayName` и не переносите имена параметров между разными библиотечными частями без проверки.

## Изменить и проверить

Для `SetGDLParametersOfElements` входной массив называется `elementsWithGDLParameters`. Каждая запись содержит `elementId` и `gdlParameters`, внутри которого передаются `name` или `index` и `value`. Не используйте похожее недокументированное имя `elementWithGDLParametersArray` и не добавляйте лишнюю оболочку к `elementId`.

Если параметр хранит ссылку на атрибут числовым индексом, передавайте индекс требуемого типа, а не название материала строкой. Для поверхности получите текущий каталог через `GetAttributesByType` с `attributeType="Surface"` и разрешите нужный индекс программно. Не подставляйте случайный индекс и не считайте все числовые параметры ссылками на поверхности: решение определяется прочитанным типом параметра.

Изменения требуют разрешённого пользователем режима работы. Сохраните прежние значения локально, сначала выполните ограниченную пробу, затем проверьте **каждый** элемент `executionResults`. Ответ MCP без `isError` может содержать `success:false` и `error`: это частичная или полная неудача команды. Не повторяйте весь изменяющий пакет автоматически, если часть операций уже выполнилась.

После успешного результата повторно прочитайте изменённые параметры и геометрию. При работе с окнами отдельно проверьте размеры и размещение через доступный `GetDetailsOfElements`, а видимый результат — в соответствующем виде Archicad. Корректная JSON-структура, отсутствие исключения и ответ модели не доказывают правильность геометрии или материалов.

Не переносите представление атрибутов между командами: числовой индекс в GDL и объект `attributeId` с `guid` в параметрах поверхности — разные контракты. При смешанном результате пакета используйте порядок восстановления из `model-edit-verification`; отсутствующий результат не считайте успехом.

При неверном результате восстановите только действительно изменённые значения из локального снимка и снова прочитайте состояние. После тайм-аута или отмены сначала выясните, применились ли изменения.

## Синтетический пример проверки ответа

```python
import json

wrapper = {"content": [{"type": "text", "text": json.dumps({
    "executionResults": [{"success": True}, {"success": False,
        "error": {"code": -1, "message": "Synthetic failure"}}]
})}]}
data = wrapper.get("structuredContent")
if data is None:
    data = json.loads(wrapper["content"][0]["text"])
failed = [item for item in data["executionResults"]
          if item.get("success") is False or item.get("error")]
assert failed  # MCP transport success does not mean every operation succeeded.
```

Пример не подключается к Archicad и не изменяет модель. Источник общих схем — [документация команд Tapir](https://enzyme-apd.github.io/tapir-archicad-automation/archicad-addon/); фактическое подключение остаётся источником доступности команды.
