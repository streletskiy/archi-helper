# Обрезка крышей или оболочкой

Сверьте команды со схемой текущего подключения. До разрешённого изменения прочитайте связи целевых элементов через `GetElementTrims` и сохраните пары с типами обрезки. Для явно заданной крыши или оболочки `TrimElements` принимает цели в `elements[].elementId`, сам режущий элемент в `trimmingElement` как объект с `guid` и при необходимости `trimType`. По схеме тип по умолчанию в этом режиме — `KeepInside`. Если `trimmingElement` опущен, схема описывает режим с крышами и оболочками из самого списка `elements`.

Ответ `TrimElements` — один `ExecutionResult` с `success` и полем `error` при отказе. После вызова прочитайте `GetElementTrims` с целями в `elements`. После декодирования оболочки MCP сопоставьте `elementTrims` с запросом по документированному порядку и проверьте длину массива. Для каждой цели ищите ожидаемую крышу или оболочку и тип в `trimmedBy[]`. Поле `trims[]` перечисляет элементы, которые обрезает сам запрошенный элемент. Пустой массив связей допустим в валидной записи. Запись с `error`, отсутствие массива или несогласованная длина оставляют соответствующий результат чтения неопределённым.

Явно синтетический ответ на запрос двух целей. Первая запись содержит связь, вторая содержит ошибку чтения.

```json
{"elementTrims":[{"trimmedBy":[{"elementId":{"guid":"00000000-0000-4000-8000-000000000001"},"trimType":"KeepInside"}],"trims":[]},{"error":{"code":-1,"message":"Synthetic lookup failure"}}]}
```

При неизвестном исходе перечитайте связи до повтора. Для разрешённого снятия подтверждённой лишней связи `RemoveElementTrims` принимает `elementPairs[]` с `elementId` цели и `trimmingElementId` крыши или оболочки. Проверьте каждую запись `executionResults`, затем перечитайте связи. Для проверки фактической геометрии требуется отдельное чтение геометрии или осмотр подходящего вида.

Проверены поставляемые схемы трёх команд версии `1.5.9` и синтетический JSON. Проверка охватывает форму запросов и ответов. Геометрия и изменение модели в PLN в этой проверке не оценивались. [Справочник команд Tapir](https://archicad-api.com/archicad-addon/)
