# Создание и клонирование видов в Карте видов

Сверьте схемы текущего подключения. `CreateViewsInViewMap` создаёт самостоятельные виды с копированием базы и настроек источника. `CloneProjectMapItemToViewMap` создаёт клон точки обзора из Карты проекта. В обеих командах каждая запись `viewsData[]` содержит `navigatorItemId` источника и `parentNavigatorItemId` папки назначения в Карте видов. Сначала проверьте папку по дереву навигатора или создайте её через `CreateViewMapFolder`, если это входит в задачу. Поле `name` допустимо только в `CreateViewsInViewMap`.

После снятия оболочки MCP прочитайте `navigatorItems[]`. В каждой записи возвращается `navigatorItemId` либо `error`. Проверяйте весь массив, даже если вызов завершился без ошибки инструмента. Отсутствующий массив или несовпадение его длины с количеством запросов оставляет часть результата неопределённой.

Явно синтетический ответ на пакет из двух записей.

```json
{"navigatorItems":[{"navigatorItemId":{"guid":"00000000-0000-4000-8000-000000000001"}},{"error":{"code":-1,"message":"Synthetic failure"}}]}
```

При частичном или неизвестном исходе перечитайте дерево Карты видов и сопоставьте полученные идентификаторы с папкой назначения. Выясните, какие виды уже созданы, и повторите только оставшиеся операции после устранения причины. При проверке запроса на конкретные настройки перечитайте настройки созданных видов отдельно.

Проверены поставляемые схемы обеих команд версии `1.1.7` и синтетические JSON-запросы и ответы. Фактическое создание и наследование настроек в PLN требуют отдельной проверки. [Изменение схемы Tapir](https://github.com/ENZYME-APD/tapir-archicad-automation/pull/776)
