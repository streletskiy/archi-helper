# JSON API: восстановление после модального диалога

Если JSON API сообщает `Invalid program status` и в полном локальном ответе прямо указано наличие открытого модального диалога, сначала завершите работу с этим диалогом. Ошибка относится к состоянию приложения; изменение полей запроса само по себе не закрывает окно.

В проверенном синтетическом случае `API.GetAllElements` при открытом диалоге создания проекта вернул `succeeded:false`, `error.code:4001` и сообщение об открытом модальном диалоге. Код без сообщения не доказывает ту же причину во всех состояниях Archicad.

## Порядок восстановления

1. Сохраните полный ответ и определите отклонённую команду. Нулевой код завершения Python не отменяет `succeeded:false` внутри полученного JSON. Для MCP сначала снимите оболочку результата.
2. Осмотрите интерфейс Archicad. Завершите именно обнаруженный диалог с сохранением или отменой намеренных правок. Не нажимайте подтверждение или отмену вслепую: у пользователя могут быть незавершённые настройки. Закрытие диалога не разрешает отменять чужую работу.
3. Повторите ограниченное чтение через то же подключение. В прямом JSON проверьте `succeeded`, отсутствие `error` и ожидаемую структуру `result`; для `API.GetAllElements` это `result.elements`.
4. Если чтение снова неудачно, сохраните новый ответ и выясните текущее состояние. Не запускайте бесконечный повтор и не считайте любое окно причиной сетевого тайм-аута.

Проверенное восстановление — отмена контролируемого тестового диалога и повтор **того же запроса чтения**, вернувший `succeeded:true` и массив `result.elements`. Перезапуск Archicad или изменение модели для этого случая не потребовались.

## Если до ошибки выполнялись изменения

Этот опыт не доказывает атомарность пакета или отсутствие ранее применённых операций. После ошибки либо тайм-аута изменяющего вызова прочитайте фактическое состояние и отделите выполненные операции от неудачных и неопределённых. Повторяйте только необходимые действия по правилам `model-edit-verification`. Закрытие диалога не является откатом модели.

## Границы подтверждения

Проверено 2026-11-02 в отдельном синтетическом PLN: Archicad 27, build 5003, Tapir 1.7.3. Отправлено по одному прямому запросу `API.GetAllElements` при открытом и закрытом диалоге; полные ответы сопоставлены независимо от текста модели. Изменяющий вызов в модальном состоянии, другие причины `4001`, другие диалоги и версии отдельно не проверялись.

[Документация Graphisoft о диалогах](https://archicadapi.graphisoft.com/documentation/dialog-boxes) описывает модальный диалог как отдельный контекст, прерывающий редактирование документа. Она не заменяет проверку конкретного ответа JSON API и состояния текущего подключения.
