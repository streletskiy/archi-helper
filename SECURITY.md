# Безопасность и данные

Техническая телеметрия PostHog и структурированные маршруты действий включены по умолчанию и выключаются в настройках приложения, включая время выполнения задачи. Содержимое проектов, переписки, файлов, скриптов и секреты не передаются. [Точный состав, ограничения доставки и удаление данных](docs/TELEMETRY.md). Публичный токен приёма событий не даёт административного доступа; персональные ключи PostHog не поставляются с приложением.

Не прикладывайте к публичным issues API-ключи, личные проекты, полную историю сессий или содержимое `%APPDATA%\Archi`.

Для сообщения об уязвимости используйте [приватный отчёт GitHub](https://github.com/streletskiy/archi-helper/security/advisories/new). Укажите версию, способ воспроизведения и ожидаемый результат без реальных секретов.

Поддерживается последняя опубликованная версия. Установленная версия автоматически обновляется из стабильных GitHub Releases. Portable обновляется вручную. Подпись Windows пока не настроена; при ручном скачивании используйте Releases этого репозитория и при необходимости сверяйте `SHA256SUMS.txt`.

Python выполняется локально с правами пользователя. Полный доступ не является песочницей. Подтверждение действия не отменяет уже выполненные изменения.
