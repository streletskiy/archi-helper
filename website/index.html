КОРОТКАЯ ИНСТРУКЦИЯ

От установки — к делу.

Три шага до первой задачи
  1. 01

    Установите помощника

    Скачайте установщик для Windows x64 и запустите его. Python, uv и MCP уже внутри.

    Скачать последнюю версию
  2. 02

    Подключите Archicad

    Откройте проект в Archicad. Через настройки помощника установите Tapir, завершите установку и перезапустите Archicad.

    Tapir связывает помощника с Archicad.
  3. 03

    Выберите AI и начните

    Войдите через lumv или ChatGPT в настройках либо укажите API-ключ своего провайдера. Выберите модель и напишите задачу.

    Например: «Какие свойства есть у стен?»

↳ Для первого знакомства выберите режим «Только просмотр». Перед изменениями сохраните резервную копию PLN.

Полная документация
Что нужно для работы?+

Windows x64, установленный Archicad с подходящей версией Tapir и доступ к AI-провайдеру. Доступные инструменты зависят от версий Archicad и Tapir; помощник использует возможности текущего подключения.

Сколько это стоит?+

Archi Helper — бесплатное приложение с открытым исходным кодом под лицензией MIT. Доступ к моделям и стоимость запросов определяет выбранный AI-провайдер.

Куда отправляются мои данные?+

История и файлы хранятся локально. Запросы и необходимые материалы отправляются выбранному AI-провайдеру. Техническая статистика включена по умолчанию; её можно отключить в настройках. Тексты чата, файлы проектов и секреты в эту статистику не входят. Подробнее о данных.

Как обновляться?+

Установленная версия сама проверяет стабильные релизы и предлагает перезапуск после завершения работы. Portable-версию нужно обновлять вручную: скачайте новый EXE из последнего релиза.

Почему Windows предупреждает об установщике?+

Установщики пока не подписаны сертификатом издателя. Скачивайте приложение только из официальных GitHub Releases; там же опубликован файл SHA256SUMS.txt для проверки скачанного файла.
