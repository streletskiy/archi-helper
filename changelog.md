# История изменений

## [0.2.4] — 2026-10-21

### Добавлено

- Уточнения текущей задачи и очередь следующих сообщений с сохранением в чате, удалением и применением по запросу.
- Отдельные рабочие папки чатов в AppData для вложений, скриптов, промежуточных файлов и результатов; кнопка «Файлы чата» и выбор места экспорта переписки.
- Markdown-база приёмов агента с инструкцией по надписи площади в конкретном штампе зоны и обязательным явным одобрением её применения.

### Исправлено

- Передача управления установщику, обработка запроса прав Windows и автоматический запуск обновлённого приложения с видимым ходом установки.
- Совместимость очереди сообщений с файлами отдельных чатов и обязательными подтверждениями действий.
- Перенос старых чатов и служебных результатов в профиль без удаления оригиналов, с сохранением доступа к изображениям и истории.
- Диагностика Python: причина остановки, исключения и stderr отделены от строк прогресса; сохраняются полный журнал и конец большого вывода.

[Подробности выпуска и установка](docs/releases/0.2.4.md).

## [0.2.3] — 2026-10-21

### Исправлено

- Мерцание изображений и скачки текста в сессии при наборе сообщения: загруженные картинки больше не создаются заново после каждого символа.
- Отображение изображений и ссылок в текущем ответе приведено к завершённым сообщениям; поступление нового текста и переключение языка сохраняют загруженные изображения.

[Подробности выпуска и установка](docs/releases/0.2.3.md).

## [0.2.2] — 2026-10-21

### Исправлено

- Проверка обновлений сразу при запуске и затем каждый час; ошибки проверки и скачивания повторяются автоматически через минуту.
- Ожидание завершения загрузки и обработка её ошибок без необходимости ручной проверки в настройках.
- Отображение хода выполнения задач и поиск инструментов Archicad.

### Добавлено

- Отдельный экран обновления вместо рабочего интерфейса: этапы проверки, загрузки, установки и запуска, процент, объём и скорость скачивания.
- Установка без отдельного окна установщика: экран остаётся видимым во время замены файлов и до готовности новой версии.
- Обработка ошибок установки и уведомление об успешном обновлении после перезапуска.
- Локальный каталог MCP, Tapir и прямого Graphisoft API с поиском, точными схемами, сигнатурами типов и выбором SDK по подключённой версии Archicad.

[Подробности выпуска и установка](docs/releases/0.2.2.md).

## [0.2.1] — 2026-10-21

### Добавлено

- Копирование сообщений пользователя и помощника, включая текущий ответ, с уведомлением о результате.
- Компактные уведомления об успешных действиях и ошибках.

### Исправлено

- Расчёт контекста в токенах с учётом лимитов модели, данных каталогов провайдеров и Models.dev, фактического расхода из API и запаса для следующего ответа.
- Удалён прежний общий порог в 180 тысяч символов; ограничения после переполнения изолированы по провайдеру, адресу API и модели и обновляются через сутки.
- Автоматическое обновление параметров существующих подключений и поддержка API без сведений о контексте или статистики потоковых ответов.

[Подробности выпуска и установка](docs/releases/0.2.1.md).

## [0.2.0] — 2026-10-21

### Добавлено

- Переключение API-провайдера и модели в чате с запоминанием модели для каждого подключения.
- Выбор поддерживаемого уровня рассуждения с предпочтением Xhigh, каталогом поддерживаемых вариантов и ручной настройкой совместимости API.
- Автоматическое сжатие рабочего контекста с архивированием полной истории и восстановлением после переполнения на стороне API.
- Свёрнутые группы вызовов инструментов с доступом к параметрам и результатам.

### Изменено

- Настройки разделены боковой навигацией на AI-провайдеров, Archicad и сведения о приложении.
- Версия, обновления, данные и конфиденциальность, встроенные компоненты и ссылки показаны отдельными блоками; версии берутся из данных сборки.
- Управление чатом собрано в одну строку, язык RU/EN вынесен в верхнюю панель.
- Установщик распаковывает файлы сразу в каталог приложения; автообновление скачивает полный установщик.
- Длительные задачи продолжаются без прежнего ограничения в 40 шагов.

### Исправлено

- Вертикальное выравнивание стрелок выпадающих меню и одинаковая высота соседних элементов форм.
- Переключение и удаление провайдеров без потери выбранной модели другого подключения.
- Передача параметров и служебного состояния рассуждения с учётом API провайдера и его ограничений.
- Выбор модели по ID применяется к редактируемому подключению.

[Подробности выпуска и установка](docs/releases/0.2.0.md).

## [0.1.0] — 2026-10-20

Первый выпуск для Windows: проекты и сессии с локальной историей, OpenAI-совместимый Chat Completions API, Archicad через MCP и Tapir, обработка PDF и изображений встроенным Python, режимы доступа, русский и английский интерфейс и автоматические обновления.

[Подробности первого выпуска](docs/releases/0.1.0.md).
