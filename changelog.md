# История изменений

## [0.2.30] — 2026-10-29

### Добавлено и улучшено

- Локальная память находок агента сохраняет технические приёмы отдельно от личных знаний и подбирает наблюдавшиеся маршруты для точного сочетания версий Archicad, сборки и Tapir.
- В библиотеке появились находки и их архив: записи можно отключать, закреплять, восстанавливать и копировать в личные знания.
- При включённом развитии знаний передаются технические карточки из разрешённых команд и полей; названия, ключевые слова и текстовые пояснения остаются локально.
- Исправлена упаковка встроенной среды для повторного использования блоков при дифференциальных обновлениях. Первый переход со старой упаковки потребует загрузить архив среды заново.

[Подробности выпуска и установка](docs/releases/0.2.30.md).

## [0.2.29] — 2026-10-28

### Исправлено и улучшено

- Исправлен запуск наблюдения вложенных JSON API-вызовов Python при строковом формате порта активного подключения Archicad.
- Встроенный справочник поясняет фильтр верхнего уровня `GetDetailsOfElements.fields` и обработку неполного набора полей ответа.
- Уточнён разбор результатов создания: массивы `elements` и `attributeIds` содержат идентификаторы либо ошибки и отличаются от `executionResults`.

[Подробности выпуска и установка](docs/releases/0.2.29.md).

## [0.2.28] — 2026-10-28

### Исправлено и улучшено

- Технические отчёты сохраняют безопасные типы исключений Python и категории известных ошибок API, включая ограничения класса элемента и недопустимое состояние Archicad.
- Вложенные JSON API-вызовы Python наблюдаются отдельно: видны частичные ошибки, неизвестный результат и ограничения покрытия без передачи скриптов и исходных значений.
- Встроенный справочник уточняет ограничение `ModifyRoofs` многоплоскостными крышами и отличие от возможностей `CreateRoofs`.
- Высота поля ввода чата автоматически подстраивается под текст сообщения.

[Подробности выпуска и установка](docs/releases/0.2.28.md).

## [0.2.19] — 2026-10-25

### Улучшено

- Ускорена установка обновлений: неизменившийся Python сохраняется после проверки SHA-256, а новая или повреждённая среда распаковывается прямо в конечный каталог. Блоковая загрузка сохранена.
- Экран обновления закрывается сразу после появления готового окна приложения, без дополнительного ожидания в одну секунду.
- Экран обновления всегда следует светлой или тёмной теме Windows, включая её изменение при открытом окне; поддерживаются системные контрастные цвета.
- Экран обновления показывает текущую операцию и прошедшее время; проверка Python дополнительно показывает процент этапа, число файлов и оценку оставшегося времени этапа.
- Исправлена неполная распаковка двух служебных файлов Python из архивов с фильтром ARM64. Состав среды проверяется до сообщения об успешной установке.

## [0.2.0] — 2026-10-21

### Добавлено

- Переключение API-провайдера и модели в чате с запоминанием модели для каждого подключения.
- Выбор поддерживаемого уровня рассуждения с предпочтением Xhigh, каталогом поддерживаемых вариантов и ручной настройкой совместимости API.
- Автоматическое сжатие рабочего контекста с архивированием полной истории и восстановлением после переполнения на стороне API.
- Свёрнутые группы вызовов инструментов с доступом к параметрам и результатам.

### Изменено

- Настройки разделены боковой навигацией на AI-провайдеров, Archicad и сведения о приложении.
- Версия, обновления, данные и конфиденциальность, встроенные компоненты и ссылки показаны отдельными блоками; версии берутся из данных сборки.
- Управление чатом собрано в одну строку, язык RU/EN вынесен в верхнюю панель.
- Установщик распаковывает файлы сразу в каталог приложения; автообновление скачивает полный установщик.
- Длительные задачи продолжаются без прежнего ограничения в 40 шагов.

### Исправлено

- Вертикальное выравнивание стрелок выпадающих меню и одинаковая высота соседних элементов форм.
- Переключение и удаление провайдеров без потери выбранной модели другого подключения.
- Передача параметров и служебного состояния рассуждения с учётом API провайдера и его ограничений.
- Выбор модели по ID применяется к редактируемому подключению.
